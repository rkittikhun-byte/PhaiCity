# PhaiCity — แผนเสียงและดนตรี

ผู้รับผิดชอบ: **Claude Code** (เสียงไม่ใช่งานกราฟิก ตามการแบ่งงานใน `CLAUDE.md`)
รายการเสียงทุกตัว แหล่งที่มา วิธีอัดเสียงเอง prompt สำหรับ AI และบรีฟจ้างนักดนตรี อยู่ใน `docs/audio/SOUND_LIST.md`
ส่วนที่ติดป้าย **[ข้อเสนอ]** ยังปรับได้

---

## 1. สถานะในโค้ดตอนนี้

- เกมเดิม (micropolisJS) **ไม่มีเสียงเลย**
- แต่ระบบจำลองเตรียมสัญญาณเสียงไว้แล้ว:
  - `src/messages.ts` มี `SOUND_HEAVY_TRAFFIC`, `SOUND_HONKHONK`, `SOUND_MONSTER`
  - ยานพาหนะใน `src/*Sprite.js` มีตัวนับ `soundCount` และเรือมี `// TODO Sound` ค้างไว้
- จึงต่อเสียงเข้าไปได้โดยไม่ต้องแก้การทำงานของระบบจำลอง แค่ฟังเหตุการณ์ที่ระบบส่งออกมา

## 2. ประเภทเสียง

| กลุ่ม | ตัวอย่าง | มาจากไหนในเกม |
|---|---|---|
| **UI** | คลิกปุ่ม เปิดหน้าต่าง เงินไม่พอ บันทึกเกม | การกดปุ่มใน `index.html` |
| **เครื่องมือ** | วางโซน (ตอกเสาเข็ม) ราดยางถนน รถไถ เดินสายไฟ ปลูกต้นไม้ | ผลของ tool (`TOOLRESULT_*`) |
| **เหตุการณ์** | ไซเรนดับเพลิง น้ำท่วม ระเบิด พายุงวงช้าง พญานาค เครื่องบินตก เมืองล้มละลาย ประชากรถึงเป้า (เสียงฆ้องหรือระนาดสั้น ๆ) | ข้อความจากระบบจำลอง (`src/messages.ts`) |
| **บรรยากาศ** | รถติดและเสียงแตร ตลาด นกและจักจั่นในป่า คลื่นทะเล เรือหางยาวในแม่น้ำ หวูดรถไฟ โรงงาน คนเชียร์ในสนาม; กลางคืนมีจิ้งหรีดและตุ๊กแก; ฝนตกในฤดูฝน (พ.ค.–ต.ค. ตามปฏิทินในเกม) | ส่วนของแผนที่ที่อยู่ในจอตอนนั้น |
| **ยานพาหนะ** | ตุ๊กตุ๊ก มอเตอร์ไซค์ รถไฟ เฮลิคอปเตอร์ เรือ | ตำแหน่ง sprite จาก `spriteManager` |
| **ดนตรี** | ธีมหลัก และเพลงประจำภาค | หน้าเมนู และภาคของจังหวัดที่กำลังเล่น |

## 3. ดนตรี [ข้อเสนอ]

- **ธีมหลัก PhaiCity:** ใช้ **ขลุ่ยไม้ไผ่** เป็นเสียงนำ ให้เข้ากับชื่อ "ไผ่"
  ใช้ในหน้าเมนูและหน้าเลือกจังหวัด
- **เพลงประจำภาค:** เป็นเพลงบรรเลงเบา ๆ เล่นวนได้ ผสมเครื่องดนตรีไทยกับดนตรีสมัยใหม่ (lo-fi / ambient)

| ภาค | เครื่องดนตรีหลัก |
|---|---|
| เหนือ | สะล้อ ซอ ซึง |
| ตะวันออกเฉียงเหนือ | แคน พิณ โปงลาง |
| กลาง | ระนาด ขิม จะเข้ |
| ตะวันออก | ขิม และเสียงบรรยากาศชายทะเล |
| ตะวันตก | ขลุ่ย จะเข้ และกลิ่นอายดนตรีมอญ |
| ใต้ | กลองทับ ปี่ใต้ |

- **แต่ละภาคควรมี 2–3 เพลง** เพื่อไม่ให้ผู้เล่นเบื่อ เพลงละ 2–4 นาที

## 4. แหล่งเสียงและลิขสิทธิ์

**เสียงเอฟเฟกต์:**
- ใช้แบบ CC0 จาก Freesound (กรองเฉพาะ CC0), Kenney หรือ OpenGameArt (เฉพาะไฟล์ที่เป็น CC0)
- บันทึกแหล่งที่มาใน `assets/audio/CREDITS.md`
- เสียงเฉพาะของไทย เช่น ตุ๊กตุ๊ก เรือหางยาว หรือตุ๊กแก อาจหาแบบ CC0 ไม่ได้ ต้องอัดเองหรือจ้างอัด

**ดนตรี มี 3 ทาง:**

| ทาง | ข้อดี | ข้อเสีย |
|---|---|---|
| **จ้างนักดนตรีไทย** (เช่น ผ่าน Fastwork) | ได้สไตล์ตรงใจ สิทธิ์ชัดเจนตามสัญญา | มีค่าใช้จ่าย |
| AI สร้างเพลง | เร็วและถูก | ต้องอ่านเงื่อนไขบริการเรื่องการใช้เชิงพาณิชย์ และสถานะลิขสิทธิ์ของงาน AI ยังไม่ชัด |
| เพลง CC0 | ฟรี | หาเพลงที่เป็นสำเนียงไทยแทบไม่ได้ |

**[ข้อเสนอ]** จ้างทำธีมหลัก ส่วนเพลงประจำภาคเลือกระหว่างจ้างกับ AI ตามงบ
ในสัญญาจ้างต้องระบุให้ชัดว่าอนุญาตให้ใช้ในเกมเชิงพาณิชย์และแจกจ่ายบนเว็บได้

**ห้ามใช้:**
- เพลงที่มีลิขสิทธิ์และเพลงดังทุกเพลง รวมถึงไฟล์บันทึกเสียงของคนอื่น
  ทำนองเพลงไทยเดิมที่หมดลิขสิทธิ์แล้วนำมาเรียบเรียงและบันทึกใหม่เองได้
- เพลงชาติ เพลงสรรเสริญพระบารมี และเพลงพระราชนิพนธ์ทุกเพลง
- บทสวดหรือเสียงพิธีกรรมทางศาสนาทุกศาสนา (สอดคล้องกับที่งดศาสนสถานในกราฟิก)
- เสียงหรือคำพูดที่ล้อเลียนสำเนียงถิ่นหรือกลุ่มชาติพันธุ์

## 5. เทคนิค

- **ที่อยู่ของโค้ด:** `src/audio/` ฝั่ง Claude Code ไฟล์เสียงอยู่ใน `assets/audio/`
- **ระบบเสียงฟังเหตุการณ์อย่างเดียว:** อ่านข้อความจากระบบจำลอง ผลของ tool และตำแหน่ง sprite
  ไม่เปลี่ยนสถานะเกม และไม่แตะ renderer
- **ไลบรารี [ข้อเสนอ]:** Web Audio API ผ่าน howler.js (MIT)
  - เสียงสั้นรวมเป็นไฟล์เดียว (audio sprite)
  - เพลงใช้แบบ streaming
- **ไฟล์:** `.ogg` และ `.mp3` สำรอง
  - เพลงต้องวนได้ไม่มีรอยต่อ
  - เพลงรวมทั้งหมดไม่เกิน ~15 MB และโหลดเฉพาะเพลงของภาคที่กำลังเล่น
- **เบราว์เซอร์ไม่ยอมเล่นเสียงจนกว่าผู้เล่นจะคลิก:** ต้องเริ่มเสียงหลังการคลิกครั้งแรก
- **การตั้งค่า:**
  - ปรับระดับเสียงแยกได้ 4 ส่วน: เพลง เอฟเฟกต์ บรรยากาศ และ UI
  - ปุ่มปิดเสียงทั้งหมด
  - จำค่าที่ตั้งไว้ใน localStorage
  - เงียบเองเมื่อสลับไปแท็บอื่น
  - ข้อความในหน้าตั้งค่ามี 2 ภาษาเหมือน UI ทั้งหมด
- **เสียงตามตำแหน่ง:**
  - ตอนนี้ (2D): คำนวณความดังและซ้าย-ขวาจากตำแหน่งบนจอ
  - เมื่อมี renderer 3D: ต้องขอให้ Codex เปิดฟังก์ชันอ่านอย่างเดียว `getCameraState()`
    (ตำแหน่งกล้อง ทิศ และระดับซูม) เป็นคำขอข้ามฝั่งผ่านเจ้าของโปรเจกต์ ตามกติกาแบ่งงาน

## 6. ลำดับงาน

| ขั้น | งาน | ต้องรอ 3D ไหม |
|---|---|---|
