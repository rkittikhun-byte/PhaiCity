# PhaiCity — แผนเสียงและดนตรี

ผู้รับผิดชอบ: **Claude Code** (เสียงไม่ใช่งานกราฟิก ตามการแบ่งงานใน `CLAUDE.md`)
รายการเสียงทุกตัว แหล่งที่มา วิธีอัดเสียงเอง prompt สำหรับ AI และบรีฟจ้างนักดนตรี อยู่ใน `docs/audio/SOUND_LIST.md`
ส่วนที่ติดป้าย **[ข้อเสนอ]** ยังปรับได้

---

## 1. สถานะในโค้ดตอนนี้

- เกมเดิม (micropolisJS) **ไม่มีเสียงเลย**
- แต่ระบบจำลองเตรียมสัญญาณเสียงไว้แล้ว:
  - `src/messages.ts` มี `SOUND_HEAVY_TRAFFIC`, `SOUND_HONKHONK`, `SOUND_MONSTER`
  - ยานพาหนะใน `src/*Sprite.js` มีตัวนับ `soundCount` และเรือมี `// TODO Sound` ค้างไว้
- จึงต่อเสียงเข้าไปได้โดยไม่ต้องแก้การทำงานของระบบจำลอง แค่ฟังเหตุการณ์ที่ระบบส่งออกมา

## 2. ประเภทเสียง

| กลุ่ม | ตัวอย่าง | มาจากไหนในเกม |
|---|---|---|
| **UI** | คลิกปุ่ม เปิดหน้าต่าง เงินไม่พอ บันทึกเกม | การกดปุ่มใน `index.html` |
| **เครื่องมือ** | วางโซน (ตอกเสาเข็ม) ราดยางถนน รถไถ เดินสายไฟ ปลูกต้นไม้ | ผลของ tool (`TOOLRESULT_*`) |
| **เหตุการณ์** | ไซเรนดับเพลิง น้ำท่วม ระเบิด พายุงวงช้าง พญานาค เครื่องบินตก เมืองล้มละลาย ประชากรถึงเป้า (เสียงฆ้องหรือระนาดสั้น ๆ) | ข้อความจากระบบจำลอง (`src/messages.ts`) |
| **บรรยากาศ** | รถติดและเสียงแตร ตลาด นกและจักจั่นในป่า คลื่นทะเล เรือหางยาวในแม่น้ำ หวูดรถไฟ โรงงาน คนเชียร์ในสนาม; กลางคืนมีจิ้งหรีดและตุ๊กแก; ฝนตกในฤดูฝน (พ.ค.–ต.ค. ตามปฏิทินในเกม) | ส่วนของแผนที่ที่อยู่ในจอตอนนั้น |
| **ยานพาหนะ** | ตุ๊กตุ๊ก มอเตอร์ไซค์ รถไฟ เฮลิคอปเตอร์ เรือ | ตำแหน่ง sprite จาก `spriteManager` |
| **ดนตรี** | ธีมหลัก และเพลงประจำภาค | หน้าเมนู และภาคของจังหวัดที่กำลังเล่น |

## 3. ดนตรี [ข้อเสนอ]

- **ธีมหลัก PhaiCity:** ใช้ **ขลุ่ยไม้ไผ่** เป็นเสียงนำ ให้เข้ากับชื่อ "ไผ่"
  ใช้ในหน้าเมนูและหน้าเลือกจังหวัด
- **เพลงประจำภาค:** เป็นเพลงบรรเลงเบา ๆ เล่นวนได้ ผสมเครื่องดนตรีไทยกับดนตรีสมัยใหม่ (lo-fi / ambient)

| ภาค | เครื่องดนตรีหลัก |
|---|---|
| เหนือ | สะล้อ ซอ ซึง |
| ตะวันออกเฉียงเหนือ | แคน พิณ โปงลาง |
| กลาง | ระนาด ขิม จะเข้ |
| ตะวันออก | ขิม และเสียงบรรยากาศชายทะเล |
| ตะวันตก | ขลุ่ย จะเข้ และกลิ่นอายดนตรีมอญ |
| ใต้ | กลองทับ ปี่ใต้ |

- **แต่ละภาคควรมี 2–3 เพลง** เพื่อไม่ให้ผู้เล่นเบื่อ เพลงละ 2–4 นาที

## 4. แหล่งเสียงและลิขสิทธิ์

**เสียงเอฟเฟกต์:**
- ใช้แบบ CC0 จาก Freesound (กรองเฉพาะ CC0), Kenney หรือ OpenGameArt (เฉพาะไฟล์ที่เป็น CC0)
- บันทึกแหล่งที่มาใน `assets/audio/CREDITS.md`
- เสียงเฉพาะของไทย เช่น ตุ๊กตุ๊ก เรือหางยาว หรือตุ๊กแก อาจหาแบบ CC0 ไม่ได้ ต้องอัดเองหรือจ้างอัด
- เสียงที่เลือกแล้วอยู่ใน `scripts/audio/sfx-manifest.json` (คัดลงเกมด้วย `npm run audio:build`) ร่างรายการแหล่งเสียงเดิม
  (SOUND_SOURCES, 11 ต.ค. 2026) ลบไปแล้ว ที่ยังต้องจำไว้คือ Freesound ที่ตรวจแล้ว **ห้ามใช้** เพราะเป็นเสียงอื่น
  ไม่ใช่ CC0 หรือไม่มีหน้า: 252327 (CC BY), 619553, 207038 (404), 787265, 675956, 607873 (CC BY), 64998 (404),
  737380 (CC BY-NC), 675837, 277028, 766736, 483598, 582855 (404), 674063 (404); และรายการ Sonniss เป็นแค่ชื่อหมวด
  ต้องเลือกไฟล์จาก bundle เอง

**ดนตรี มี 3 ทาง:**

| ทาง | ข้อดี | ข้อเสีย |
|---|---|---|
| **จ้างนักดนตรีไทย** (เช่น ผ่าน Fastwork) | ได้สไตล์ตรงใจ สิทธิ์ชัดเจนตามสัญญา | มีค่าใช้จ่าย |
| AI สร้างเพลง | เร็วและถูก | ต้องอ่านเงื่อนไขบริการเรื่องการใช้เชิงพาณิชย์ และสถานะลิขสิทธิ์ของงาน AI ยังไม่ชัด |
| เพลง CC0 | ฟรี | หาเพลงที่เป็นสำเนียงไทยแทบไม่ได้ |

**[ข้อเสนอ]** จ้างทำธีมหลัก ส่วนเพลงประจำภาคเลือกระหว่างจ้างกับ AI ตามงบ
ในสัญญาจ้างต้องระบุให้ชัดว่าอนุญาตให้ใช้ในเกมเชิงพาณิชย์และแจกจ่ายบนเว็บได้

**ห้ามใช้:**
- เพลงที่มีลิขสิทธิ์และเพลงดังทุกเพลง รวมถึงไฟล์บันทึกเสียงของคนอื่น
  ทำนองเพลงไทยเดิมที่หมดลิขสิทธิ์แล้วนำมาเรียบเรียงและบันทึกใหม่เองได้
- เพลงชาติ เพลงสรรเสริญพระบารมี และเพลงพระราชนิพนธ์ทุกเพลง
- บทสวดหรือเสียงพิธีกรรมทางศาสนาทุกศาสนา (สอดคล้องกับที่งดศาสนสถานในกราฟิก)
- เสียงหรือคำพูดที่ล้อเลียนสำเนียงถิ่นหรือกลุ่มชาติพันธุ์

## 5. เทคนิค

- **ที่อยู่ของโค้ด:** `src/audio/` ฝั่ง Claude Code ไฟล์เสียงอยู่ใน `assets/audio/`
- **ระบบเสียงฟังเหตุการณ์อย่างเดียว:** อ่านข้อความจากระบบจำลอง ผลของ tool และตำแหน่ง sprite
  ไม่เปลี่ยนสถานะเกม และไม่แตะ renderer
- **ไลบรารี [ข้อเสนอ]:** Web Audio API ผ่าน howler.js (MIT)
  - เสียงสั้นรวมเป็นไฟล์เดียว (audio sprite)
  - เพลงใช้แบบ streaming
- **ไฟล์:** `.ogg` และ `.mp3` สำรอง
  - เพลงต้องวนได้ไม่มีรอยต่อ
  - เพลงรวมทั้งหมดไม่เกิน ~15 MB และโหลดเฉพาะเพลงของภาคที่กำลังเล่น
- **เบราว์เซอร์ไม่ยอมเล่นเสียงจนกว่าผู้เล่นจะคลิก:** ต้องเริ่มเสียงหลังการคลิกครั้งแรก
- **การตั้งค่า:**
  - ปรับระดับเสียงแยกได้ 4 ส่วน: เพลง เอฟเฟกต์ บรรยากาศ และ UI
  - ปุ่มปิดเสียงทั้งหมด
  - จำค่าที่ตั้งไว้ใน localStorage
  - เงียบเองเมื่อสลับไปแท็บอื่น
  - ข้อความในหน้าตั้งค่ามี 2 ภาษาเหมือน UI ทั้งหมด
- **เสียงตามตำแหน่ง:**
  - ตอนนี้ (2D): คำนวณความดังและซ้าย-ขวาจากตำแหน่งบนจอ
  - เมื่อมี renderer 3D: ต้องขอให้ Codex เปิดฟังก์ชันอ่านอย่างเดียว `getCameraState()`
    (ตำแหน่งกล้อง ทิศ และระดับซูม) เป็นคำขอข้ามฝั่งผ่านเจ้าของโปรเจกต์ ตามกติกาแบ่งงาน

## 8. สถานะขั้น 1–2 (11 ต.ค. 2026)

**โค้ด** (`src/audio/`):
- `catalog.ts`: รหัสเสียงทุกตัว ไฟล์ ช่องเสียง ความดัง ระยะห่างขั้นต่ำก่อนเล่นซ้ำ และความยาวสูงสุดของเสียงยาว
- `engine.ts`: เล่นเสียงหลังผู้เล่นคลิกครั้งแรก, 4 ช่อง (effects, ambience, ui, music) ใต้ปุ่มปิดเสียง,
  เสียงบรรยากาศแบบวนที่ค่อย ๆ ดังขึ้นหรือเบาลง, เงียบเมื่อสลับแท็บ, จำค่าใน localStorage (`phaicity.audio`)
- `gameAudio.ts`: ฟังเหตุการณ์จากเกมอย่างเดียว (ข้อความระบบจำลอง ผลของ tool สัญญาณ `SOUND_*` และ tile บนจอ)
  - เสียงเครื่องมือดังซ้ายหรือขวาตามตำแหน่งที่คลิก
  - ทุก 3 วินาทีนับ tile บนจอ แล้วผสมเสียงป่าและเสียงโรงงาน
  - สุ่มเสียงสั้นตามที่เห็นและฤดู: คนเชียร์ เครื่องบิน ฟ้าร้อง (พ.ค.–ต.ค.) นกนางนวล ไก่ขัน
- `uiSounds.ts`: เสียงปุ่มทุกปุ่มผ่าน listener เดียว
- `index.ts`: ปุ่ม 🔊 บนหัวเว็บ และแถบปรับเสียงในหน้าต่างตั้งค่า (ปรับแล้วมีผลทันที ไม่ขึ้นกับปุ่มตกลง/ยกเลิก)

**แก้โค้ดเกมเดิมน้อยที่สุด:** `spriteManager.js` ส่งต่อสัญญาณ `SOUND_*` ที่ยานพาหนะส่งอยู่แล้ว
(เดิมไม่มีใครฟัง) และ `game.js` เรียก `toolUsed` หลังใช้ tool โดยไม่เปลี่ยนการทำงานของระบบจำลอง

**ไฟล์เสียง:** 37 ไฟล์ CC0 (Kenney 22, Freesound 15) รวม 5.4 MB ใน `assets/audio/sfx/`
- สร้างด้วย `npm run audio:build -- --raw <โฟลเดอร์เสียงดิบ>` จาก `scripts/audio/sfx-manifest.json`
- สคริปต์เขียน `assets/audio/CREDITS.md` ใหม่ทุกครั้ง และไม่ยอมรับแหล่งที่ไม่ใช่ CC0
- เป็น `.ogg` อย่างเดียว เพราะเครื่องนี้ไม่มี ffmpeg (Chrome, Edge และ Firefox เล่นได้ Safari บางรุ่นอาจไม่มีเสียง)

**เสียงชั่วคราวที่ควรเปลี่ยนเมื่อมีของจริง** (เลือกจากชื่อไฟล์ ยังไม่มีใครฟังตรวจ):
- ไฟไหม้ใช้เสียงสัญญาณเตือนโรงงาน แทนไซเรนแบบไทย
- น้ำท่วมและพายุงวงช้างใช้ฟ้าร้อง ส่วนพญานาคและแผ่นดินไหวใช้เสียงครืนเดียวกัน
- เสียงโรงงานเป็นเสียงเครื่องยนต์สังเคราะห์จาก Kenney
- **เพิ่ม 12 ต.ค. 2026 (CC0 จาก Freesound, เจ้าของอนุมัติให้ดาวน์โหลด):**
  - เสียงถนนกรุงเทพฯ (`amb.city`) ดังตามถนนบนจอ และดังขึ้นตามรถติด
  - ตลาดไทย (`amb.market`) เมื่อเห็นย่านการค้ามาก ควรฟังตรวจว่าไม่มีเพลงมีลิขสิทธิ์เปิดอยู่ในพื้นหลัง
  - คลื่น (`amb.waves`) เมื่อน้ำกินพื้นที่บนจอเกิน 15%
  - ฝน (`amb.rain`) ตกเป็นช่วง ๆ ละ 30–90 วินาทีในฤดูฝน ฟ้าร้องเปลี่ยนมาดังเฉพาะตอนฝนตก
  - หวูดเรือ (`SOUND_HONKHONK`) เมื่อเรือในเกมแล่น
- ยังไม่มี: เสียงกลางคืน (เกม 2D ยังไม่มีกลางวัน/กลางคืน) และยานพาหนะไทย เช่น ตุ๊กตุ๊ก เรือหางยาว (รอ renderer 3D)
- เสียงวนโหลดเมื่อจำเป็นเท่านั้น: ตอนเริ่มเกมโหลดเสียงสั้นราว 0.6 MB ส่วนเสียงวน 8 MB โหลดเมื่อต้องใช้
- เสียงงานก่อสร้าง (861482) และโรงงานร้าง (240895) ที่โหลดมามีขนาด 5.7 MB และ 4 MB จึงยังไม่ใช้

## 9. สถานะขั้น 3: ดนตรี (11 ต.ค. 2026)

**โค้ดเสร็จแล้ว ใช้เพลง CC0 ชั่วคราว 6 ไฟล์ (ด้านล่าง)** ระหว่างรอเพลงจริง

- `src/audio/music.ts`: ตัวเล่นเพลง
  - หน้าเริ่มเกมเล่นรายการ `theme` ในเมืองเล่นรายการของภาคที่จังหวัดนั้นอยู่
  - เพลงยาวใช้แบบ streaming (`<audio>` ต่อเข้าช่อง music ของ `engine.ts`) ไม่ต้องโหลดทั้งไฟล์ก่อนเล่น
  - เปลี่ยนรายการแบบ crossfade 2.5 วินาที สุ่มลำดับโดยไม่ซ้ำเพลงเดิมติดกัน
  - เพลงจบแล้วพักเงียบ 20–45 วินาทีก่อนเพลงถัดไป (รายการที่มีเพลงเดียวก็พักก่อนเล่นซ้ำ) ให้ได้ยินเสียงเมืองบ้าง
  - ข้ามไฟล์ที่เล่นไม่ได้ และหยุดชั่วคราวเมื่อสลับแท็บ
- `assets/audio/music/tracks.json`: รายชื่อเพลงของแต่ละรายการ
- `assets/audio/music/CREDITS.md`: เครดิตและ license ของเพลงทีละไฟล์ แยกจากเครดิตเอฟเฟกต์
  ที่ `npm run audio:build` เขียนใหม่ทุกครั้ง เพราะเพลงอาจมาได้หลายทาง (CC0, จ้างทำ, AI)
- หน้าตั้งค่ามีแถบ "เพลง" แล้ว
