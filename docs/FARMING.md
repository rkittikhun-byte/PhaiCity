# เกษตรและประมง (Farms and fishing)

เจ้าของโปรเจกต์ขอ (13 ต.ค. 2026): "ทำเกษตรกับประมงต่อเลย" เป็นทรัพยากรสองอย่างสุดท้ายที่มีผลในเกม
(`docs/PROVINCE_PROFILE.md`) โค้ดอยู่ที่ `src/farming.ts`

## สำหรับผู้เล่น

| | ไร่นา | ท่าเรือประมง |
|---|---|---|
| ขนาดและราคา | 3×3 ฿300 วางบนที่โล่ง | 3×3 ฿1,200 ต้องติดน้ำ (ทะเล แม่น้ำ หรือบึง) |
| สร้างได้ | จังหวัดที่มีที่ดินเกษตร (ระดับ 1 ขึ้นไป) | จังหวัดที่มีประมง (ระดับ 1 ขึ้นไป) |
| ขายได้ต่อเดือน (ระดับ 3) | ราว ฿4–7 ขึ้นกับน้ำใต้ดินใต้ไร่ หน้าแล้งได้ครึ่งเดียว | ราว ฿14 เมื่อปลาเต็ม ลดตามปลาที่เหลือ |
| ได้อีก | ดึงโรงงานแปรรูปเกษตร (ความต้องการโรงงานเพิ่ม) และมีงานให้คน | ดึงตลาดและร้านอาหาร (ความต้องการร้านค้าเพิ่ม) และมีงานให้คน |
| เสีย | สูบน้ำใต้ดินรอบไร่ แย่งน้ำกับโรงผลิตน้ำประปา สารเคมีลงดินเล็กน้อย (ชั้น "สารพิษ") และช่วง ก.พ.–เม.ย. การเผาไร่ทำให้เกิดหมอกควันรอบไร่ 4 ช่อง ซึ่งนับเป็นมลพิษและทำให้นักท่องเที่ยวหนี | ท่าเรือมากเกินปลาในจังหวัดหมด ฟื้นตัวช้า ๆ เมื่อจับน้อยลง และน้ำเสียแถวท่าเรือ (มลพิษเกิน 80) ทำให้จับปลาได้ครึ่งเดียว |
| ข่าว | หมอกควัน (ไม่เกินปีละครั้ง) | ปลาเริ่มหมด และน้ำเสียแถวท่าเรือ (ไม่เกินปีละครั้ง) |

- รายได้จากไร่นาและท่าเรือสะสมทั้งปี แล้วเข้าคลังพร้อมภาษี หน้างบประมาณแยกบรรทัด "รายได้จากเกษตรและประมง"
- ปลาเป็นของทั้งจังหวัด (0–100%) บันทึกไว้กับเมือง
- ท่าเรือหนึ่งแห่งจับได้ยั่งยืน (ปลาเหลือราว 90%) ห้าแห่งทำให้ปลาเหลือไม่ถึงหนึ่งในสามในราว 9 ปี แปดแห่งในราว 2 ปีครึ่ง
- นโยบายเจ้าเมือง (`docs/POLICIES.md`): ห้ามเผาไร่ ไม่มีหมอกควันแต่ผลผลิตไร่เหลือ 80%; ปิดอ่าว ท่าเรือหยุดจับช่วง ก.พ.–เม.ย. ปลาจึงฟื้น
- น้ำเสียของเมืองที่ไม่ได้บำบัดทำให้น้ำแถวท่าเรือเสียด้วย (`docs/WASTE.md`) และกระทงที่ค้างในน้ำหลังลอยกระทง (`docs/GAME_DESIGN.md` ข้อ 5)
- ไร่ของเมืองในเดือนเผาเพิ่มควันในอากาศของเดือน (ไร่ละ 0.03 สูงสุด 0.3: `_weatherMonth` ใน `src/simulation.js`, `docs/GAME_DESIGN.md` ข้อ 4)

## ระบบจำลอง

- **ไทล์ที่ใช้:**
  - ไร่นาใช้ไทล์ 974–982 (CHURCH3 ศูนย์กลาง 978)
  - ท่าเรือประมงใช้ไทล์ 983–991 (CHURCH4 ศูนย์กลาง 987)
  - 992–1000 เป็นอาคารขยะและน้ำเสีย (`docs/WASTE.md`) 1001–1009 เป็นสถานี (`docs/TRANSIT.md`) ยังว่าง 1010–1018 (`src/tileValues.ts`)
- **ตรวจก่อนสร้าง:** `CityCommands` (`farmProblem`) ปฏิเสธเมื่อจังหวัดไม่มีที่ดินเกษตรหรือประมง และปฏิเสธท่าเรือที่ไม่ติดน้ำ แผนที่ฝึกเล่นถือว่าระดับ 2
- **ทุกรอบการสำรวจ:** นับไร่และท่าเรือ (`Farming.farmFound` / `harbourFound`) แล้วนับงานเข้า `census.indPop`
- **ทุกต้นเดือน (phase 9):** `Farming.month` คำนวณรายได้เข้า `budget.farmFund` สูบน้ำใต้ดิน ใส่สารเคมีลงชั้นสารพิษของเหมือง วางหมอกควันในเดือนเผาไร่ และลดหรือฟื้นปลา
- **ความต้องการ:** `valves.farmFactories` เพิ่มโรงงานที่เมืองควรมี และ `valves.fishMarkets` เพิ่มร้านค้า
- **มลพิษ:** หมอกควันเพิ่มในการคำนวณมลพิษผ่าน `extraPollution`

## ภาพ 3D

ตอนนี้ (21 ต.ค. 2026) ยังไม่มีโมเดลของตัวเอง: ตัววาดเมืองใช้บล็อกอุตสาหกรรมแทน ไร่นาเป็น `ind.block_0_0` สีเขียวหม่น ท่าเรือประมงเป็น
`ind.block_0_1` หันหาน้ำ (`extendedPlacement` ใน `src/render3d/city/tileModels.ts`) ไอคอนเครื่องมือมีแล้ว (`assets/icons/tools/farm.svg`,
`fishing.svg`) และควันเผาไร่เห็นเป็นหมอกควันสีน้ำตาลของอากาศ (`src/render3d/city/weather.ts`)

ยังต้องทำ: Prompt F1 ใน `docs/3d/CODEX_PROMPTS.md` (RENDERER_SPEC 6F)
- ไร่นาตามภาค:
  - นาข้าวในภาคกลางและอีสาน
  - ไร่ข้าวโพดบนเนินในภาคเหนือ
  - อ้อยและมันสำปะหลังในภาคตะวันออกและตะวันตก
  - สวนยางและปาล์มในภาคใต้
- ท่าเรือประมง: สะพานปลา เรือหางยาว ห้องเย็น และตลาดปลา
- ควันจากตัวไร่ในเดือนเผา (ตอนนี้มีแต่หมอกควันทั่วเมือง)

## ต่อไป

- ชลประทาน: ไร่ที่อยู่ติดคลองหรือแม่น้ำไม่ต้องพึ่งน้ำใต้ดิน (ตอนนี้คลองที่ขุดทำให้น้ำใต้ดินรอบ ๆ มากขึ้นแล้ว `docs/CANALS.md`
  แต่ไร่ยังไม่ได้น้ำจากคลองตรง ๆ)
- เลี้ยงกุ้งและปลาในบ่อ (ระดับ aquaculture)
- ขายผลผลิตให้จังหวัดเพื่อนบ้านในโหมดออนไลน์
