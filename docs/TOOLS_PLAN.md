# แผนเครื่องมือและระบบที่ยังไม่ได้ทำ

เจ้าของโปรเจกต์เห็นด้วยกับข้อเสนอ (13 ต.ค. 2026):
- "เขียนแผนไว้ในกรณีที่ยังไม่ได้ทำ"
- "แต่ละ tool มันจะมีระดับของมันอยู่"
- "ทำตามลำดับที่แนะนำเลย"

ไฟล์นี้เป็นแผนและบันทึกงาน เมื่อเรื่องไหนทำแล้วจะมีเอกสารของเรื่องนั้นแยก และติ๊กไว้ที่นี่

## 2. การศึกษาและสาธารณสุข

| อาคาร | ได้ | เสีย |
|---|---|---|
| โรงเรียน | ราคาที่ดินรอบ ๆ ขึ้น คนอยากอยู่ แรงงานมีการศึกษา | ค่าบำรุงรายปี |
| มหาวิทยาลัย | แรงงานฝีมือ ดึงโรงงานไฮเทคที่ควันน้อย และอุตสาหกรรมแร่หายาก | แพง ต้องมีประชากรถึงระดับหนึ่งก่อน |
| โรงพยาบาล | คนอายุยืน ลดผลจากมลพิษ สารพิษ และหมอกควันต่อคน | ค่าบำรุงสูง |

- ระดับการศึกษาของเมือง (0–100) วัดจากที่นั่งเรียนเทียบกับประชากร มีผลต่อชนิดโรงงานที่อยากมาและควันของโรงงาน
- ระดับสุขภาพ (0–100) มีผลต่อการเติบโตของเขตบ้าน และลดผลเสียจากมลพิษ

## 3. ขยะและน้ำเสีย

| อาคาร | ได้ | เสีย |
|---|---|---|
| บ่อฝังกลบ | ถูก รับขยะได้มาก | ซึมลงดินและน้ำใต้ดิน (ชั้นสารพิษ) มีกลิ่น ราคาที่ดินรอบ ๆ ตก และเต็มได้ |
| โรงเผาขยะ | ไม่เต็ม | ควัน มลพิษอากาศ |
| โรงคัดแยกรีไซเคิล | สะอาด มีงาน ได้ขายของรีไซเคิล | แพง รับขยะได้น้อย |
| โรงบำบัดน้ำเสีย | น้ำในแม่น้ำและทะเลสะอาด ปลากลับมา นักท่องเที่ยวชอบ | แพง ต้องมีไฟฟ้า |

- เมืองผลิตขยะตามประชากรและนักท่องเที่ยว ขยะที่ไม่มีที่ทิ้งกลายเป็นมลพิษในเขตบ้านและร้านค้า ข่าวเตือน "ขยะล้นเมือง"
- น้ำเสียจากเมืองทำให้น้ำแถวท่าเรือประมงเสีย (ต่อกับ `docs/FARMING.md`)

## 4. นโยบายเจ้าเมือง

เปิดปิดได้ในหน้าต่างใหม่ เป็นคำสั่งของ `CityCommands` ทุกนโยบายมีค่าใช้จ่ายรายปี

| นโยบาย | ได้ | เสีย |
|---|---|---|
| ห้ามเผาไร่ | หมอกควันหาย | ผลผลิตไร่ลด |
| ค่าธรรมเนียมนักท่องเที่ยว | รายได้ต่อคนเพิ่ม | นักท่องเที่ยวลด |
| รณรงค์ประหยัดน้ำ | ใช้น้ำน้อยลง | ความพอใจของคนลด |
| ปิดอ่าวช่วงปลาวางไข่ | ปลาฟื้นเร็ว | รายได้ประมงช่วงนั้นหาย |
| ผังเมืองสีเขียว | น้ำใต้ดินและราคาที่ดินดี | สร้างเขตใหม่ได้น้อยลง |
| สงกรานต์ประหยัดน้ำ | น้ำไม่หายช่วงสงกรานต์ | นักท่องเที่ยวช่วงสงกรานต์ลด |
| ภาษีมลพิษโรงงาน | ควันโรงงานลด ได้เงิน | ความต้องการโรงงานลด |

## 9. ระดับของเครื่องมือ

ทุกเครื่องมือมีระดับในการ์ดเหนือแถบเครื่องมือ (5 ช่อง เว้นแต่ระบุ)
- **สร้างใหม่:** เลือกระดับก่อนวาง
- **ยกระดับ:** อาคารที่มีอยู่ยกระดับได้ทีละขั้นด้วยปุ่มอัปเกรด จ่ายส่วนต่าง แบบเดียวกับถนน
- **ระดับยิ่งสูง:** ได้มากขึ้น แต่ค่าบำรุงหรือผลเสียก็มากขึ้นด้วย

| เครื่องมือ | ระดับ | สถานะ |
|---|---|---|
| ถนน | ลูกรัง, ลาดยาง, คอนกรีต 2/4/6/8 เลน, มอเตอร์เวย์, ทางด่วน และอัปเกรด | **ทำแล้ว** (`docs/ROADS.md`) |
| ทางรถไฟ | รางเดี่ยว, รางคู่, รางไฟฟ้า, รถไฟความเร็วสูง | ยังไม่ทำ |
| สายไฟฟ้า | เสาไม้, เสาคอนกรีต, สายแรงสูง, สายใต้ดิน | ยังไม่ทำ |
| สวนสาธารณะ | สวนหย่อม, สวนสาธารณะ, สวนพฤกษศาสตร์, ป่าในเมือง | ยังไม่ทำ |
| เขตบ้าน ร้านค้า โรงงาน | ความหนาแน่นสูงสุดที่ยอมให้: บ้านเดี่ยว, ทาวน์เฮาส์, อาคารชุด, ตึกสูง, ตึกระฟ้า | ยังไม่ทำ |
| ตำรวจ | ป้อมตำรวจ, สถานีตำรวจ, สภ.ใหญ่, กองบังคับการ | ยังไม่ทำ |
| ดับเพลิง | จุดดับเพลิง, สถานีดับเพลิง, ศูนย์บรรเทาสาธารณภัย | ยังไม่ทำ |
| โรงไฟฟ้า | ชนิดทำแล้ว (`docs/POWER_PLANTS.md`) แต่ละชนิดยังขยายกำลังผลิตได้ 3 ขั้น | ชนิดทำแล้ว ขั้นกำลังผลิตยังไม่ทำ |
| ประปา | โรงผลิตน้ำเล็ก กลาง ใหญ่ และหอถังเล็ก ใหญ่ | ยังไม่ทำ |
| เหมือง ไร่นา ท่าเรือประมง | ขนาดเล็ก กลาง ใหญ่: ได้มากขึ้น แต่หมดเร็วขึ้นและมีผลเสียมากขึ้น | ยังไม่ทำ |
| โรงเรียน | อนุบาล, ประถม, มัธยม, อาชีวะ, มหาวิทยาลัย | ทำพร้อมข้อ 2 |
| โรงพยาบาล | รพ.สต., รพ.ชุมชน, รพ.จังหวัด, รพ.ศูนย์ | ทำพร้อมข้อ 2 |
| ขยะ | บ่อฝังกลบ, โรงเผา, โรงคัดแยก, โรงไฟฟ้าขยะ (และโรงบำบัดน้ำเสีย) | ชนิดทำแล้ว (`docs/WASTE.md`) ขนาดของแต่ละชนิดยังไม่ทำ |
| ท่าเรือ | ท่าเรือเล็ก, ท่าเรือพาณิชย์, ท่าเรือน้ำลึก | ยังไม่ทำ |
| สนามบิน | สนามบินเล็ก, สนามบินภูมิภาค, สนามบินนานาชาติ | ยังไม่ทำ |
| สนามกีฬา | สนามกีฬาจังหวัด, สนามกีฬาแห่งชาติ | ยังไม่ทำ |
