# PhaiCity Style Guide: หนึ่ง theme สำหรับทุกอย่าง

เจ้าของขอ (18 ต.ค. 2026): "อยากให้ทุก object หรือ 3d หรือ เว็บเป็นไปแนวทางเดียวกัน ... ให้ ai ทุกตัวทำงานในการ design
ให้เหมือนๆ กัน 100% มันจะได้ไม่แตกแยกหรือมั่วซั่ว"

ไฟล์นี้คือกติกาเรื่องหน้าตาของเกมทั้งหมด ทั้งหน้าเว็บ ไอคอน โมเดล 3D แสง คน และภาพ concept ใหม่
AI ทุกตัวและคนที่มาทำงานต้องอ่านก่อนทำงานที่มีผลต่อหน้าตา

- **ถ้าเอกสารอื่นพูดเรื่องสี แสง หรือสไตล์ต่างจากไฟล์นี้ ให้เชื่อไฟล์นี้** ข้อยกเว้นเดียวคือกฎลิขสิทธิ์และสิ่งต้องห้ามใน
  `CLAUDE.md` ซึ่งชนะเสมอ
- เรื่องเทคนิคยังอยู่ที่เอกสารเดิม เช่น หน่วย งบสามเหลี่ยม และ factory ของโมเดลอยู่ใน `docs/3d/MODEL_SPEC.md`

## 0. กติกาสำหรับ AI ทุกตัว (สั้นที่สุด)

1. **ห้ามคิดสีขึ้นมาเอง** ทุกสีมาจาก `src/theme/tokens.ts` เท่านั้น
   - **หน้าเว็บ:** ใช้ `var(--ph-…)` จาก `css/theme.css` โดยเลือกชื่อตามหน้าที่ก่อน เช่น `--ph-ink`, `--ph-accent`
     ถ้าไม่มีชื่อที่ตรง ค่อยใช้ขั้นของ ramp เช่น `--ph-sand-300` ห้ามเขียน `#hex`, `rgb()` หรือชื่อสีอย่าง `white` ในไฟล์ CSS
   - **3D:** ใช้ `SCENE` (สีตาม material key, สีคน, แสง) ห้ามเขียน `0x…` ใหม่ในโค้ดโมเดล
   - **ถ้าต้องการสีที่ไม่มี:** เพิ่มใน `tokens.ts` ก่อน แล้วบอกเจ้าของในรายงานว่าเพิ่มสีอะไร เพราะอะไร
2. แก้ `tokens.ts` แล้วต้องรัน `npm run theme:css` ทุกครั้ง อย่าแก้ `css/theme.css` ด้วยมือ
3. **ก่อนส่งงาน** `npx jest --coverage=false test/theme.ts` ต้องผ่าน การทดสอบนี้จับได้ 3 อย่าง
   - CSS ที่มีสีดิบ
   - ตัวแปรที่ไม่มีอยู่จริง
   - ข้อความที่อ่านยาก (ต่ำกว่า WCAG AA 4.5:1)
   
   นอกจากนี้ยังนับสีที่เขียนตรงในโค้ดแต่ละโฟลเดอร์ ตัวเลขนี้ลดลงได้ แต่ห้ามเพิ่ม
4. **วางงานเทียบกับภาพอ้างอิง** (หัวข้อ 1) ทุกครั้ง ถ้าเป็นโมเดลให้เทียบในแกลเลอรี (`npm run gallery`) ถ้ามองแล้วไม่ใช่โลกเดียวกัน ถือว่ายังไม่เสร็จ
5. **ถ้าไม่แน่ใจ ให้ถามเจ้าของ** ห้ามเดาแล้วตั้งสไตล์ใหม่เอง

## 2. บุคลิกของภาพ (อ่านให้ขึ้นใจ)

- **ไดโอรามาภาพประกอบ** มองแบบ isometric เหมือนภาพวาดเมืองจิ๋วบนก้อนดิน ไม่ใช่ภาพถ่ายหรือภาพยนตร์
- **บ่ายแก่สีทอง แสงคงที่** แดดส่องมาจากขวาของภาพ เยื้องมาทางคนดูนิดหนึ่ง เงย ~46° เงาจึงตกไปทางซ้ายล่าง
- **เงาเป็นสีม่วงลาเวนเดอร์ ไม่ใช่สีเทาหรือดำ** ด้านเงาของทุกสีเบนไปทางม่วง ไม่ใช่แค่มืดลง (แผงสีมีคู่ให้ทุกสี)
- **ลงสีเรียบ 2–3 ระดับ** (แดด ครึ่งแดด เงา) มีเส้นขอบน้ำตาลเข้ม `#3B1E10` รายละเอียดวาดเป็นเส้นและชิ้นส่วน
  เช่น แนวกระเบื้อง แนวไม้ บานเกล็ด ไม่ใช้ texture ภาพถ่าย
- **โทนอุ่นทั้งภาพ** ได้แก่ ทราย ไม้สัก ดินเผา ทอง และเขียวมะกอก ส่วนเขียวสดใช้กับนาข้าวและใบไม้เท่านั้น ฟ้าและเขียวอมฟ้าใช้กับน้ำ
  ไม่ใช้ฟ้าซีด เทาเย็น หรือพาสเทลชมพูม่วง
- **ของเล็กใหญ่เกินจริงเล็กน้อย** คน กระถาง ต้นกล้วย รถเข็น และเสาไฟต้องอ่านออกตอนมองจากกล้องเกม
- **อ่านด้วยรูปทรงก่อน** หลังคา ชายคา ใต้ถุน ชาน บันได และกันสาด ต้องจำได้จากเงาโครงร่าง
- **เมืองไทยที่มีชีวิต** ศาลพระภูมิ โอ่ง ต้นกล้วย มะพร้าว แผงผลไม้ สายไฟ แอร์ แท็งก์น้ำ ป้ายภาษาไทย (ชื่อสมมติ)

## 3. สี

### 3.1 Ramp (ครอบครัวสี): `RAMPS` ใน `tokens.ts`

ทุก ramp ไล่จากสว่าง (0/50) ไปมืด (900/950) หน้าเว็บใช้ผ่าน `var(--ph-<ramp>-<ขั้น>)` หรือ
`rgba(var(--ph-<ramp>-<ขั้น>-rgb), อัลฟา)`

| ramp | มาจาก concept | ใช้กับ |
|---|---|---|
| `sand` | พื้นหลังทราย กระดาษ หมึก | พื้น การ์ด ตัวหนังสือ เส้น (สีกลางทั้งหมด) |
| `clay` | กระเบื้องดินเผา | สิ่งที่เลือกอยู่หรือกดได้ (accent) |
| `gold` | หลังคาจาก แดดบ่าย | ไฮไลต์ หน้าเริ่มเกม |
| `rice` | นาข้าว ใบตอง | ข่าวดี การเติบโต |
| `water` | น้ำเขียวหม่น | แผนที่ น้ำ ข้อมูล |
| `lavender` | เงา | เงาทุกชนิด การตั้งค่า |
| `chili` | พริก | อันตราย ภัยพิบัติ ยกเลิก |

| ตัวแปร | ขั้น | ใช้กับ |
|---|---|---|
| `--ph-paper`, `--ph-paper-hi` | sand 100 / 0 | พื้นการ์ดและหน้าต่าง |
| `--ph-glass`, `--ph-glass-strong`, `--ph-glass-edge` | sand 0 ที่ 0.8 / 0.94 / 0.7 | การ์ดกระจกฝ้าของ HUD |
| `--ph-ink`, `--ph-ink-dim`, `--ph-line` | sand 800 / 600 / 300 | ตัวหนังสือ ตัวหนังสือรอง เส้นแบ่ง |
| `--ph-accent`, `--ph-accent-strong`, `--ph-accent-soft`, `--ph-on-accent` | clay 500 / 600 / 500@0.16, sand 0 | ปุ่มหลัก ของที่เลือก (ตัวหนังสือบนปุ่มทึบให้ใช้คู่ `accent-strong` + `on-accent`) |
| `--ph-gold`, `--ph-gold-deep` | gold 300 / 600 | ไฮไลต์ |

## 4. หน้าเว็บ

**สองบรรยากาศ ใช้ token ชุดเดียวกัน**

| บรรยากาศ | หน้าไหน | พื้น | ตัวหนังสือ | ไฮไลต์ |
|---|---|---|---|---|
| **กลางวัน** | ในเมือง: HUD เมนูซ้าย แถบบน dock เครื่องมือ หน้าต่างทุกบาน การ์ดภารกิจ | กระจกฝ้าสีครีม `--ph-glass` + blur `--ph-blur-glass` | `--ph-ink` | `--ph-accent` |
| **กลางคืน** | หน้าแรก (title) หน้าเลือกจังหวัด หน้าโหลด About | `--ph-night` น้ำตาลเข้มอุ่น ห้ามใช้ดำอมเขียว | `--ph-night-ink` | ทอง (`gold` ramp) |

- **ตัวอักษร:** `--ph-font-body` (Sarabun) และ `--ph-font-display` (Chunk) สำหรับชื่อเกม ขนาดใน HUD `--ph-size-hud` (9 px) และไม่ใช้ตัวหนา
- **มุมโค้ง:** `--ph-radius-chip` / `-button` / `-card` / `-pill` ห้ามใช้ค่าอื่น
- **เงาการ์ด:** `--ph-shadow-card` (ม่วงอ่อน ไม่ใช่ดำ)
- **การเคลื่อนไหว:** `--ph-motion-quick` / `-normal` ผ่าน `src/motion.ts`
- **ห้าม:**
  - สีเขียวอมฟ้าแบบ UI เดิม
  - ฟ้า Material/Bootstrap
  - พาสเทลเย็น
  - เงาดำทึบ
  - ไล่สีรุ้ง
  - กรอบหนา
- **สีประจำเครื่องมือ** (`data-colour` ใน `index.html`, เส้นรอบเครื่องมือบนแผนที่) และ**สีของชั้นแผนที่** (`src/cityMap.ts`) เป็นสีข้อมูล
  ยังไม่ได้ย้ายเข้า theme เมื่อแก้ ให้ย้ายเข้า `tokens.ts`

## 5. โลก 3D

ตอนนี้ `SCENE.adopted = false` คือตัวเรนเดอร์ยังเป็น PBR แบบเดิม แผนเปลี่ยนอยู่ใน `assets/review/3d-recommendation.md` ขั้นที่ 4
เมื่อเปลี่ยนแล้วให้ตั้ง `adopted = true` และแก้หัวข้อนี้ ระหว่างนี้งานใหม่ทุกชิ้นต้องเล็งไปที่ภาพข้างล่างนี้:

- **แสง:** `SCENE.light` แดด `sun` จากทิศ `sunDirection` + แสงรอบตัวลาเวนเดอร์ `ambient` ไม่มี HDRI กับตึก ไม่ tone map
  เป็นกลางวันคงที่ (กลางคืนเป็นตัวเลือก)
- **ลงสี:** `MeshToonMaterial` 3 ระดับตาม `SCENE.toonRamp` สีตาม `SCENE.materials` ใบไม้ใช้ texture แค่เป็นรูตัด (alpha)
- **เส้นขอบ:** `SCENE.outline` ทำเป็น post-process ขอบจาก normal + depth
- **ท้องฟ้าและหมอก:** `SCENE.sky` เป็นโทนทราย ห้ามใช้ฟ้าซีด
- **โมเดล:**
  - **รูปทรงก่อนรายละเอียด** หลังคาไทยชันและชายคายื่น ใต้ถุน ชาน บันได กันสาด บานเกล็ดไม้แทนกระจกในยุค 1–3
  - **ต้นไม้เป็นก้อนใบใหญ่** แบบ concept ไม่ใช่แผ่นใบโปร่ง (แผ่นใบรกมากเมื่อมีเส้นขอบ)
  - **ไม่มีบ้านทรงยุโรป** (จั่วชัน ผนังขาวหรือชมพู ขอบหน้าต่างเขียว)
  - **ของเล็กขยายได้** ราว 1.3–1.6 เท่า เพื่อให้อ่านออก (รอเจ้าของยืนยันขนาด)
  - สีจาก material key เสมอ ถ้าต้องการสีเฉพาะ ให้เพิ่มคู่ใน `SCENE` ก่อน
- **โมเดลที่มีอยู่:** แบ่งเป็นกอง (ก) ใช้ได้, (ข) ปรับสี, (ค) ปั้นใหม่ ไว้ใน `assets/review/3d-recommendation.md` ขั้นที่ 6

## 7. คน

- ยึดชีท `assets/concept/people_era*_v3.jpg` สัดส่วนในเกมประมาณ 4–4.5 หัว (ชีทหัวโต ~3.5 คนในฉากเมือง ~4.5–5)
- ในเกมคนสูงแค่ 10–20 px สิ่งที่ต้องอ่านออกคือเงาโครงร่าง (งอบ ไม้คาน จีวร หมวกกันน็อก) กับสี 2–3 ก้อน

- พระสงฆ์ให้ทำด้วยความเคารพ ห้ามโดนรถชนหรือโดนภัยพิบัติแบบตลก

## 9. สิ่งต้องห้ามและเรื่องที่รอเจ้าของตัดสิน

- **สิ่งต้องห้าม** ตาม `CLAUDE.md` (ข้อ 8 ในกฎลิขสิทธิ์): ห้ามแบรนด์จริง ตราครุฑ สัญลักษณ์ราชวงศ์ กาชาด พระพุทธรูป

- **รอตัดสิน:**
  - **หน้าจั่วบนบ้านและตึกแถว:** concept มีปั้นลมปลายงอนบนบ้าน และหน้าจั่วประดับบนตึกแถวยุค 3 ต้องตัดสินว่าใช้ส่วนไหนได้ ระหว่างนี้ใช้ปั้นลมเรียบ ไม่มีปลายงอน
  - **ทิศแดด:** ผูกกับโลก หรือหมุนตามกล้อง
  - **กล้องเริ่มต้น:** หมุน 45° หรือไม่
  - **ขนาดของประกอบฉาก:** ขยายเท่าไร

## 10. การเปลี่ยน theme

- **เจ้าของเป็นคนอนุมัติ** AI เสนอได้ แต่ห้ามเปลี่ยนค่าเดิมใน `tokens.ts` เองโดยไม่ได้รับคำสั่ง (เพิ่มสีใหม่ได้ แต่ต้องบอก)
- **ขั้นตอน:** แก้ `src/theme/tokens.ts` → `npm run theme:css` → `npx jest --coverage=false test/theme.ts` → ดูหน้าเกมและแกลเลอรี
  → จดในบันทึกข้างล่าง
- **เมื่อย้ายสีจากโค้ดเข้า theme ได้แล้ว:** ลดตัวเลขใน `BASELINE` ของ `test/theme.ts` ลงตามจริง (ตัวเลขห้ามเพิ่ม)
