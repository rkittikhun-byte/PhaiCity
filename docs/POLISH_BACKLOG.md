# PhaiCity — งานเก็บรายละเอียดก่อนเปิดตัว

รายการที่เจ้าของโปรเจคเลือก "เก็บไว้ทำตอนใกล้เสร็จ" ผู้รับผิดชอบคือ Claude Code เว้นแต่ระบุไว้

## หน้าแรกและการเริ่มเกม (บันทึก 11 ต.ค. 2026)

เจ้าของโปรเจคหาทางเลือกจังหวัดไม่เจอ เพราะปุ่ม "เลือกจังหวัด" เป็นปุ่มสีขาวอยู่ล่างสุดของ 4 ปุ่ม

- [ ] ให้ "เลือกจังหวัด" เป็นปุ่มหลัก ใหญ่และอยู่บนสุด พร้อมคำอธิบายสั้น ๆ ว่าเลือกจังหวัดที่จะเป็นเจ้าเมือง
- [ ] ย้ายปุ่มแผนที่สุ่มเดิม (เล่นแผนที่นี้ / สุ่มแผนที่ใหม่) ไปเป็นทางเลือกรองใต้หัวข้อ "แผนที่สุ่ม (โหมดฝึก)"
- [ ] เพิ่มปุ่ม "เมนูหลัก" ในเกม ให้ถามก่อนว่าจะบันทึกเมืองไหม แล้วกลับหน้าแรก (ตอนนี้ต้องกด F5)
- [ ] ปุ่ม "โหลดเกมเดิม" บอกชื่อเมืองและจังหวัดที่บันทึกไว้

## เสียง

- [ ] ฟังตรวจเสียงชั่วคราวทุกตัว และเปลี่ยนตัวที่ไม่เข้า (รายการใน `docs/audio/AUDIO_PLAN.md` ข้อ 8)
