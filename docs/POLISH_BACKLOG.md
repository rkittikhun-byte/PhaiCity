# PhaiCity — งานเก็บรายละเอียดก่อนเปิดตัว

รายการที่เจ้าของโปรเจคเลือก "เก็บไว้ทำตอนใกล้เสร็จ" ผู้รับผิดชอบคือ Claude Code เว้นแต่ระบุไว้

## หน้าแรกและการเริ่มเกม (บันทึก 11 ต.ค. 2026)

เจ้าของโปรเจคหาทางเลือกจังหวัดไม่เจอ เพราะปุ่ม "เลือกจังหวัด" เป็นปุ่มสีขาวอยู่ล่างสุดของ 4 ปุ่ม

- [x] ให้ "เลือกจังหวัด" เป็นปุ่มหลัก ใหญ่และอยู่บนสุด พร้อมคำอธิบายสั้น ๆ ว่าเลือกจังหวัดที่จะเป็นเจ้าเมือง
- [x] ย้ายปุ่มแผนที่สุ่มเดิม (เล่นแผนที่นี้ / สุ่มแผนที่ใหม่) ไปเป็นทางเลือกรองใต้หัวข้อ "แผนที่สุ่ม (โหมดฝึก)"
- [x] เพิ่มปุ่ม "เมนูหลัก" ในเกม ให้ถามก่อนว่าจะบันทึกเมืองไหม แล้วกลับหน้าแรก (ตอนนี้ต้องกด F5)
- [x] ปุ่ม "โหลดเกมเดิม" บอกชื่อเมืองและจังหวัดที่บันทึกไว้ (เป็นปุ่ม "เล่นต่อ: ชื่อเมือง")

- [x] เรื่องเล่าเปิดเกมแบบเลื่อนจอ เลือกภาค แล้วซูมเข้าไปเลือกจังหวัด พร้อมเงินตั้งต้น ความยาก และทรัพยากร (11 ต.ค. 2026)
- [x] แอนิเมชันเลื่อนเข้าออกของหน้าจอ หน้าต่าง แผง และปุ่ม แบบเมนูเครื่องเกม (11 ต.ค. 2026)
- [ ] ภาพประกอบเรื่องเล่า: ตอนนี้ใช้แผนที่จริงซูมและไล่สี ต่อไปเรนเดอร์ภาพ 3D ของแต่ละภาค (งานกราฟิกเป็นของ Claude Code ตั้งแต่ 13 ต.ค. 2026)
- [x] จุดเด่นและจุดอ่อนของภาคมีผลจริงในเกม ปรับได้ทั้ง 6 ภาคและ 77 จังหวัดใน `data/province-rules.json` (12 ต.ค. 2026)
- [x] หน้าหลังบ้านแก้กติกาและทรัพยากรของภาคและจังหวัด ใช้ในเครื่องผ่าน `npm run dev` (13 ต.ค. 2026, `docs/PROVINCE_PROFILE.md`)
- [ ] ย้ายหน้าหลังบ้านไปใช้ฐานข้อมูลของเซิร์ฟเวอร์และล็อกอินเจ้าของ เมื่อเปิดเซิร์ฟเวอร์ (ONLINE_PLAN 5.2)
- [ ] หน้าหลังบ้าน: แก้ภัยตามฤดูได้ด้วย

## ระดับของเครื่องมือ (เจ้าของโปรเจค 12 ต.ค. 2026)

คลิกเครื่องมือแล้วการ์ดเหนือแถบเครื่องมือแสดงเครื่องมือนั้นกับ 5 ช่องระดับ (`src/toolLevels.ts`) ช่องเหล่านี้ใช้เป็นตัวเลือกของปุ่มแล้ว
(ชนิดโรงไฟฟ้า ขยะ เหมือง โรงเรียน โรงพยาบาล สถานี ฯลฯ) และเป็นระดับจริงของบางเครื่องมือ (สถานะ 21 ต.ค. 2026):
ถนน 8 ระดับพร้อมปุ่มอัปเกรด (`src/roadLevels.ts`), จวน 6 ระดับตามยศ (`src/rulerHouse.ts`), ตำรวจ 4 ระดับ (ป้อม สถานีเดิม
สถานีใหญ่ กองบัญชาการ) และดับเพลิง 3 ระดับ (จุดดับเพลิง สถานีเดิม ศูนย์บรรเทาสาธารณภัย) พร้อมเครื่องมือยกระดับอาคาร
`building_upgrade` (`LEVEL_GROUPS` ใน `src/buildingLevels.ts`); เครื่องมืออื่นยังมีระดับเดียว

- [ ] ออกแบบระดับของแต่ละเครื่องมือ เช่น ถนน: ดินแดง ลาดยาง คอนกรีต ทางรถไฟ: รางเดี่ยว รางคู่ ไฟฟ้า: เสาไม้ เสาคอนกรีต
  (ถนน ตำรวจ ดับเพลิง จวน ทำแล้ว; สายไฟเลิกใช้แล้วตั้งแต่ 15 ต.ค. 2026 เพราะไฟเดินตามถนน; ทางรถไฟยังมีแบบเดียว)
- [x] **ชนิดถนน (เจ้าของ 13 ต.ค. 2026, ทำแล้ว ดู docs/ROADS.md):** ลูกรัง, ลาดยาง, คอนกรีต 2 / 4 / 6 / 8 เลน, มอเตอร์เวย์, ทางด่วน (เก็บค่าผ่านทาง)
  ทำหลังระบบประปา ต้องถามเจ้าของ: ราคาและค่าบำรุงแต่ละแบบ, รถที่รับได้, เสียงและมลพิษ, ราคาที่ดินข้างทาง,
  มอเตอร์เวย์และทางด่วนเข้าเขตตรง ๆ ไม่ได้ (ต้องมีทางเชื่อม), ค่าผ่านทาง, ถนนลูกรังของรัฐอัปเกรดได้ไหม;
  การ์ดระดับต้องมีมากกว่า 5 ช่องสำหรับถนน
- [x] **ปุ่มอัปเกรดถนน (เจ้าของ 13 ต.ค. 2026, ทำแล้ว):** ยกระดับถนนที่สร้างแล้วทีละขั้น 1 → 2 → 3 → 4 ไปเรื่อย ๆ
  (ลูกรัง → ลาดยาง → คอนกรีต 2 เลน → 4 → 6 → 8 → มอเตอร์เวย์ / ทางด่วน) โดยไม่ต้องรื้อสร้างใหม่ จ่ายเฉพาะส่วนต่างราคา
  เป็นคำสั่งใหม่ใน CityCommands (เช่น `{ type: 'upgrade', x, y }` หรือลากผ่านทั้งสาย) ให้เซิร์ฟเวอร์ตรวจได้
- [x] ตัวเกม: แต่ละระดับมีราคา ค่าดูแล และผลต่างกัน (เช่น ถนนคอนกรีตรับรถได้มาก พังช้า) ต้องเพิ่มค่าในแผนที่ให้รู้ว่าช่องไหนเป็นระดับไหน
  และคำสั่ง `tool` ต้องบอกระดับ (CityCommands) ให้เซิร์ฟเวอร์ตรวจได้
  (ทำแล้ว: ถนนมีราคา ค่าบำรุง รถที่รับได้ เสียง ต่อระดับ `ROAD_SPECS` ใน `src/roadLevels.ts` ระดับต่อช่องใน `gameMap.roadLevels`;
  ตำรวจและดับเพลิงมีราคา ค่าบำรุง ผล ต่อระดับใน `LEVEL_GROUPS` ระดับต่ออาคารใน `gameMap.buildingLevels` ซึ่งเซฟเก็บในช่อง
  `buildings` ตั้งแต่ 20 ต.ค. 2026; ทุกระดับเป็นชื่อเครื่องมือของตัวเอง เช่น `road_concrete4`, `police_hq` คำสั่ง `tool` จึงบอกระดับในตัว)
- [ ] โมเดล 3D ของแต่ละระดับ และไอคอนของแต่ละระดับ (ไอคอนทำแล้ว 15 ต.ค. 2026: ทุกเครื่องมือมีไอคอน `assets/icons/tools/`
  รวมทุกระดับของตำรวจและดับเพลิง; ถนนวาดตามระดับของแต่ละช่องแล้ว `src/render3d/city/roadCurves.ts`;
  ยังขาด: ตำรวจและดับเพลิงทุกระดับยังวาดด้วยโมเดลเดียว เพราะภาพ 3D ยังไม่อ่าน `buildingLevels`)
