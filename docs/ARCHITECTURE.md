# สถาปัตยกรรมและโครงสร้างระบบเกม PhaiCity (Unified Game Architecture)

เอกสารฉบับนี้รวบรวมโครงสร้างสถาปัตยกรรมทั้งหมดของ **PhaiCity** (เกมสร้างและบริหารเมืองธีมประเทศไทยระดับ Cities: Skylines บนเว็บเบราว์เซอร์ด้วย Three.js) ไว้ในที่เดียว แทนที่เอกสารย่อยที่กระจัดกระจายเดิมทั้งหมด

---

## 1. ภาพรวมสถาปัตยกรรม (Core Engine & Data Flow)

PhaiCity แยกส่วน **แกนจำลองเมือง (`CityCore`)** ออกจาก **ส่วนแสดงผล 3D (`CityView3D`)** และ **UI (`index.html`)** อย่างเด็ดขาด เพื่อให้เมืองเดียวกันสามารถรันในเบราว์เซอร์, ใน Web Worker, ในชุดทดสอบอัตโนมัติ (`autoPlayer`) และบนเซิร์ฟเวอร์ออนไลน์ (`server/`) ได้ผลลัพธ์ตรงกัน 100% (Deterministic Replay)

```
       ผู้เล่น (คลิกเครื่องมือ / ตั้งนโยบาย)           เซิร์ฟเวอร์ / AutoPlayer (รันคำสั่งซ้ำ)
                    │                                           │
                    ▼  CityCommand ({ type, ... })              ▼
┌──────────────────────── CityCore (src/core/cityCore.ts) ────────────────────────┐
│ • World State: GameMap + CityLayers (ระดับถนน, น้ำบาดาล, ที่ดิน, โซนละเอียด 2m) │
│ • Deterministic RNG: src/random.ts (ห้ามใช้ Math.random หรือเวลาเครื่อง)        │
│ • Object Registry: CityObject → Building (Community / Central) & Vehicle       │
│ • Simulation Loop: เดินเวลาทีละ Step (768 steps = 1 ปี / 48 ticks = 12 เดือน)   │
│ • Monthly Systems: ประปา, ไฟฟ้า, ขยะ, การเกษตร, เหมือง, ท่องเที่ยว, ความพอใจ  │
│ • Command Log: บันทึกทุกคำสั่งพร้อมหมายเลข Step สำหรับตรวจสอบย้อนหลัง          │
└───────────────────────────────────────┬─────────────────────────────────────────┘
                                        │ อ่านสถานะอย่างเดียว (Read-Only Snapshot)
        ┌───────────────────────────────┼───────────────────────────────┐
        ▼                               ▼                               ▼
┌──────────────────────┐    ┌───────────────────────┐    ┌────────────────────────┐
│ 3D Renderer (Three)  │    │ Frosted-Glass HUD UI  │    │ Audio & Ambient Engine │
│ src/render3d/city/   │    │ Inspector / Overlays  │    │ src/audio/             │
└──────────────────────┘    └───────────────────────┘    └────────────────────────┘
```

### กฎเหล็กของสถาปัตยกรรม (Hard Architectural Invariants)
1. **Simulation ปราศจาก DOM:** โค้ดใน `src/core/`, `src/objects/` และไฟล์คำนวณจำลองเมืองห้ามอ้างอิง `window`, `document` หรือ jQuery
2. **Deterministic 100%:** การสุ่มในระบบจำลองต้องผ่าน `Random` ของเมืองเท่านั้น ส่วนการสุ่มทางกราฟิกใน `src/render3d/` ต้องใช้ `src/render3d/rng.ts` ที่ผูกกับพิกัด `(x, y)` เท่านั้น
3. **เปลี่ยนเมืองผ่าน `CityCommands` เท่านั้น:** ผู้เล่นและ UI เปลี่ยนแปลงเมืองได้เฉพาะผ่าน `CityCore.apply(command)` (`src/cityCommands.ts`)
4. **Renderer อ่านอย่างเดียว (Read-Only View):** `src/render3d/` อ่านสถานะจาก `GameMap`, `CityLayers` และ `BlockMap` เท่านั้น ห้ามเขียนค่ากลับลงแผนที่หรือเปลี่ยนสถานะเกม

## 3. ระบบสเกลแผนที่จริง 3 ระดับ และการขยายกรอบอำเภอ (Map Scales & District Frame)

PhaiCity รองรับแผนที่ 3 รูปแบบ โดยใช้หน่วยในโลก 3D คือ **1 ช่องแผนที่ = 10 หน่วย 3D (`TILE_M = 10`)**:

| ประเภทแผนที่ | ขนาด 1 ช่องจริง (`tileSizeM`) | ขนาดแผนที่ (ช่อง) | อัตราส่วนโมเดล (`realUnits`) | คำอธิบาย |
|---|---|---|---|---|
| **1. แผนที่อำเภอสเกลจริง (District / City Map)** | **16 เมตร** | กรอบเริ่ม `480 × 480` (7.7×7.7 กม.) ขยายได้ถึงทั้งอำเภอ | `10 / 16 = 0.625` (ขนาดเท่าของจริงเป๊ะ) | สเกลหลักระดับ Cities: Skylines (`data/maps/district/TH-40-*.json`) ถนน 2 เลนกว้างตามจริง อาคารย่อสัดส่วน `0.625` |
| **2. แผนที่จังหวัดย่อส่วน (Whole-Province Map)** | **110 – 1,030 เมตร** | สูงสุด `304 × 304` (ราว 30,000 ช่องในจังหวัด) | `1.0` | ย่อทั้งจังหวัดลงในแผนที่เดียว มีทางหลวงลูกรังและทางรถไฟเชื่อมจังหวัดข้างเคียง |
| **3. แผนที่สุ่ม (Practice Map)** | **10 เมตร** | `120 × 100` | `1.0` | โหมดฝึกซ้อมดั้งเดิม |

### ระบบกรอบอำเภอที่ขยายได้ (`District Frame` — `src/cityFrame.ts`, `src/geo/districtFrame.ts`)
* อำเภอจริงมีขนาดใหญ่ (เช่น อ.เมืองขอนแก่น กว้าง `42 × 46.6` กม. หรือ `2,624 × 2,912` ช่อง)
* เพื่อให้จำลองได้ลื่นไหล เกมจะตัดกรอบการเล่น (`frame`) เริ่มต้นที่ **`480 × 480` ช่อง (15 × 15 บล็อกที่ดิน)** รอบตัวเมือง
* ผู้เล่นเริ่มต้นด้วยที่ดิน **3 × 3 บล็อก** (บล็อกละ `32 × 32` ช่อง = `512 × 512` เมตร) และใช้เครื่องมือ **ซื้อที่ดิน (`landTool.ts`, `landBlocks.ts`)** ขยายอาณาเขตได้ตามยศเจ้าเมือง (`4 → 12 → 30 → 60 → 120` บล็อก)
* เมื่อผู้เล่นซื้อที่ดินเข้าใกล้ขอบกรอบไม่ถึง 2 บล็อก ระบบ `Game.growFrame()` จะขยายกรอบออกไปด้านนั้นอีก **4 บล็อก** พร้อมเลื่อนพิกัดข้อมูลทุกชั้นในเซฟ (`reframeSave`) โดยอัตโนมัติ

## 4. ระบบวางผังเมืองและระบายเขต 3 ระดับ (Zoning & Lot System)

1. **ช่องเขตละเอียดตามแนวโค้งถนน (`ZoneCells` — `src/zoneCells.ts`, `src/render3d/city/zoneCellsView.ts`):**
   * บนแผนที่อำเภอที่มี `cellZones: true` (เช่น อ.เมืองขอนแก่น) สองข้างของถนนทุกสายที่อนุญาตให้สร้างอาคารติดได้ จะมีตารางช่องเขตที่หมุนเอียงขนานไปตามแนวโค้งจริงของถนน (`roadGeometry.ts`) ลึกออกไปถึง 32 เมตรจากขอบถนน: ช่องละ 4 ม. ลึก 8 แถว (`CELL_DEPTH`) เป็นแปลงสองแปลงซ้อนกัน 4 แถวแรกเป็นแปลงติดถนน อีก 4 แถวเป็นแปลงด้านหลัง (`PLOT_ROWS`, `plotTileOfCell`) แปลงรวม 2×2 จึงเกิดริมถนนเส้นเดียวได้ (เจ้าของโปรเจกต์ 18 ต.ค. 2026)
   * มุมทางแยกเป็นของถนนเส้นเดียว คือเส้นที่วิ่งผ่าน ถ้าไม่มีก็เส้นที่ใหญ่หรือยาวกว่า: แถวช่องของเส้นนั้นวิ่งไปจนชนขอบอีกเส้น และอีกเส้นเริ่มแถวต่อจากนั้น มุมจึงเป็นขอบตรงสองด้าน แทนแนวทแยงหยักที่มีช่องโหว่ (`CORNER_FIRST`) ช่องที่ชนถนนกลางแถวถูกตัดสั้นเหลือ ¾ หรือ ½ ช่อง (`span`) และช่องที่ใส่ไม่ลงเพราะชนช่องอื่นจะลองเลื่อนตามแถวไปเติมช่องว่าง
   * ผู้เล่นใช้แปรงระบายสี (เขียว = บ้าน, น้ำเงิน = ร้านค้า, เหลือง = โรงงาน) หรือลากกรอบสี่เหลี่ยมโดย **ไม่ข้ามเส้นกึ่งกลางถนน** (`cellsInArea`)
   * เมื่อพื้นที่ในช่อง 16 ม. ถูกระบายเกินครึ่งหนึ่ง ระบบ `syncCellPlots` จะสร้างแปลงอาคารและหันหน้าอาคารตั้งฉากกับเส้นโค้งถนนที่ใกล้ที่สุด (`roadSnap`)
2. **แปลงเดี่ยว (`Painted Plots` 16×16 ม. — `src/plots.ts`):**
   * แต่ละแปลงพัฒนาได้ **5 ระดับ** ตามความหนาแน่น ราคาที่ดิน น้ำ และไฟฟ้า:
     * **ที่อยู่อาศัย (`plot.res_1` – `5`):** บ้านเดี่ยว → ทาวน์เฮาส์ → อพาร์ตเมนต์เล็ก → แฟลต 6–8 ชั้น → คอนโดสูง
     * **พาณิชย์ (`plot.com_1` – `5`):** ร้านโชห่วย → ตึกแถว → อาคารพาณิชย์ 4–5 ชั้น → สำนักงาน 8–12 ชั้น → ตึกสำนักงานสูง
     * **อุตสาหกรรม (`plot.ind_1` – `4`):** อู่/โรงงานเล็ก → โกดัง → โรงงานมีปล่อง → โรงงานมีถัง
3. **แปลงรวมขนาดใหญ่ (`Merged Lots` 2×2 แปลง = 32×32 ม. — `lotOf` ใน `src/plots.ts`):**
   * เมื่อแปลงชนิดเดียวกัน 4 แปลงเรียงเป็นสี่เหลี่ยม 2×2 และพัฒนาถึงระดับ 4 ขึ้นไป (หรือโรงงานระดับ 3) จะยุบรวมเป็นอาคารขนาดใหญ่ (`lot.res_4–5`, `lot.com_4–5`, `lot.ind_3–4`)

## 5. ระบบโครงข่ายถนนโค้ง 8 ระดับ และทางรถไฟ (`RoadLevels`, `RoadCurves` & `drawPaths`)

### 5.1 โหมดการวาดถนน รางรถไฟ และสายไฟ (`src/drawPaths.ts`, `src/drawModes.ts`)
* รองรับ 5 โหมดการวาด: **เส้นตรง (`straight`)**, **เส้นโค้งจุดดัดเดียว (`curve`)**, **เส้นโค้ง 2 จุดดัด (`curve2` / S-curve)**, **วาดอิสระ (`free`)**, และ **ตารางผังเมือง (`grid` ทุกๆ 7 ช่อง)**
* มีระบบ **จัดแนวอัตโนมัติ (`Snapping`)** เข้าหาหัวมุมถนนเดิม มุม 90°/180°/45° และระยะห่างบล็อกมาตรฐาน พร้อมป้ายบอกความยาวจริง มุม และราคาขณะลาก
* **คลิกขวาบนแผนที่ (เจ้าของโปรเจกต์ 18 ต.ค. 2026):** วางเครื่องมือที่ถืออยู่ ทิ้งเส้นที่วาดค้าง และปิดการ์ดเครื่องมือที่เปิดค้างไว้ (`cancelDraft`, `closeToolTray` ใน `src/toolDock.ts`) ถึงไม่ได้ถือเครื่องมือก็ปิดการ์ด; คลิกขวาแล้วลากยังหมุนกล้องเหมือนเดิม
* **คลิก A ไป B (เจ้าของโปรเจกต์ 18 ต.ค. 2026: "คลิกจุด A และ B มันควรจะเริ่มจากจุด A ไปถึง B"):** คลิกใช้ตำแหน่งของคลิกเอง ไม่ใช่ตำแหน่งเมาส์ที่ขยับครั้งล่าสุด (`src/inputStatus.js`); กดค้างแล้วลากจะสร้างเส้นทันทีก็ต่อเมื่อยังไม่มีเส้นที่วาดค้าง และลากไกลอย่างน้อย 2 ช่อง (`game.inputStatus.lineDragged`) คลิกที่เมาส์ขยับเล็กน้อยจึงยังเป็นคลิก
* **ระยะจัดแนวตามการซูม (`snapReach`, `MIN_SNAP_REACH` 1.5, `MAX_SNAP_REACH` 4, `END_SNAP_REACH` 3 ใน `src/drawPaths.ts`):** ดูดเข้าถนนเดิมราว 18 พิกเซลบนจอ (อย่างน้อย 1.5 ช่อง) และดูดเข้าปลายถนนได้ไกลกว่า (อย่างน้อย 3 ช่อง) ปลายถนนมาก่อน การดัดเข้าแนว 45° แนวเส้นเดิม และแนวห่าง 7 ช่อง จะไม่เลื่อนจุดไกลเกินระยะนั้น และวงกลมจุดเริ่มแสดงตรงที่เส้นจะเริ่มจริง
* **จุดต่อบนถนนรอบเมาส์ (`game.snapDots`, `SNAP_DOT_REACH` 5, owner 18 Oct 2026):** ขณะถือเครื่องมือถนนหรือราง แต่ละช่องของเส้นชนิดเดียวกันในรัศมี 5 ช่องรอบเมาส์มีจุดขาวเล็กบนเส้นกลาง ปลายถนนที่ไม่มีอะไรต่อเป็นวงขาวใหญ่กว่า และจุดที่คลิกแล้วจะลงเด่นที่สุด (วงขาวหนาขอบเข้ม มีจุดขาวตรงกลาง อย่างน้อยราว 26 พิกเซล) ทุกอย่างคงขนาดบนจอไม่ว่าซูมเท่าไร (`overlay.ts` ToolOutline)
* **ตัวเลขขณะวาดเส้น (`src/drawReadout.ts`):** ป้ายซูมข้างแถบกล้อง ("1 ช่อง = 33 px") และข้างเมาส์บอก x, y, z (ความสูงพื้น เมตร) ของจุดใต้เมาส์ จุดที่คลิกแล้วจะลง และเหตุผลที่ย้าย, จุด A, ช่องที่วางไม่ได้เป็นสีแดง (`estimateTiles`); หลังสร้างเสร็จ มุมขวาล่างสรุปจุดที่คลิกกับจุดที่ใช้ และจำนวนช่องที่วางได้พร้อมเหตุผล
* **กรอบเครื่องมืออยู่บนสุด:** กรอบอาคาร เส้นตัวอย่าง และช่องระบายเขต วาดโดยไม่ทดสอบความลึก (`cityToolMaterial`, `cityDrawMaterial`, `zoneCellsView`) เนิน ถนน และต้นไม้จึงไม่บัง; การ์ดเครื่องมือมี tooltip บอกชื่อกับราคา (`src/toolDock.ts`)
* **ที่ดินของอาคารเห็นเต็มแปลง (เจ้าของโปรเจกต์ 18 ต.ค. 2026):** อาคารของเจ้าเมืองที่ชิดถนนบนแผนที่เมืองวาดเล็กกว่าช่องของมัน จึงมีสนามหญ้า (หรือลานคอนกรีตใต้โรงงาน/โรงไฟฟ้า) คลุมทุกช่องของแปลง 3×3 ขึ้นไป (`RoadCurves.lots`) ใต้ตัวอาคาร ที่ที่อาคารจองไว้จึงตรงกับที่เห็น และช่องที่สร้างถนนทับไม่ได้ (สีแดง ที่ของอาคาร) ไม่ดูเป็นพื้นว่างอีก

(`NODE_LIFT`) ถนนจึงไม่โผล่ทะลุเมื่อพื้นหักมุมที่ขอบช่อง
* **ถนนและรางแต่ละเส้นที่วาด (`src/roadPieces.ts`, เจ้าของโปรเจกต์ 18 ต.ค. 2026: "ถนนที่สร้างไปแล้ว และฉันสร้างต่อ จะต้องไม่เปลี่ยนรูป ถนนอีก", "ทำทางรถไฟแบบเดียวกันด้วย"):** การลากถนนหรือราง 1 ครั้ง (1 stroke) คือ 1 เส้น มีเลขของตัวเอง (`gameMap.roadPieces`, 2 ไบต์ต่อช่อง, บันทึกในเซฟเป็น `roadPieces`, `CityCommands` ใส่เลขให้ช่องที่เพิ่งกลายเป็นถนน) แล้ว `networkOf` / `roadLines` ทำให้ถนนเส้นเก่าไม่เปลี่ยนรูปเลยเมื่อสร้างต่อ:
  * สร้างต่อจากปลายถนน: ถนนเก่าจบที่ช่องปลายเหมือนเดิม (เดิมเกมเอาสองเส้นมาเกลี่ยเป็นเส้นเดียว ปลายถนนเก่าจึงงอเข้าหาถนนใหม่ได้ถึงเกือบ 2 ช่อง); ถ้าเส้นใหม่หักไม่เกิน 30° (`SMOOTH_JOINT_DEG`) เส้นใหม่ออกจากรอยต่อตามทิศถนนเก่าแล้วค่อยโค้งเข้าแนวของตัวเองภายใน 6 ช่อง (`bendStart`, `JunctionShape.smooth`, ไม่มีจาน) ถ้าหักมากกว่านั้นเป็นมุม มีจานกลมปิดรอยต่อ
  * จัดแนวต่อจากปลาย (`snapAlong`, `game.lineEndWay`, ป้าย "ต่อตามแนวเส้นเดิม"): เริ่มวาดที่ปลายถนนหรือรางที่ไม่มีอะไรต่อ คลิกถัดไป (ปลายเส้นตรง หรือจุดดัดของเส้นโค้ง) ที่ห่างจากแนวต่อของเส้นเดิมไม่เกิน 7° จะดูดเข้าแนวนั้น เส้นโค้งจึงออกจากถนนเดิมได้เนียน
  * ทางแยก: ถนนวิ่งผ่านทางแยกได้เฉพาะตามเส้นของตัวเอง ถนนเก่าจึงเป็นเส้นหลักเสมอ; ถนนเฉียงที่แตะขั้นบันไดของถนนเก่า 2 จุดในกรอบ 2×2 ต่อกันแค่จุดเดียว; กลุ่มช่องทางแยกที่ติดกัน (knot) รวมเฉพาะช่องของเส้นเดียวกัน และถนนเส้นอื่นมารวมกันที่ช่องหนึ่งของเส้นนั้นแทนการย้ายกลางกลุ่ม
  * ถนนและรางก่อนมีเลข หรือที่มากับแผนที่ เป็นเลข 0 และต่อกันแบบเดิม; ทางตัดถนนกับรางเก็บเลขของเส้นที่มีอยู่ก่อน
  * **รูปถนนคิดครั้งเดียวตอนวาด (เจ้าของโปรเจกต์ 18 ต.ค. 2026: "ถ้าลบ ไม่ต้องใช้ฟังก์ชั่นนี้ ให้ถนนมันอยู่กับที่ห้ามขยับ"):** แต่ละเส้นเก็บช่องที่ลากผ่านตามลำดับ (`gameMap.roadPaths[piece]` = `{from, to, tiles}`, บันทึกในเซฟเป็น `roadPaths`, `CityCommands.followPath`) แล้ว `networkOf().frozen(piece)` คิดเส้นโค้งจากช่องเหล่านั้นครั้งเดียว รวมการโค้งออกจากปลายเส้นเก่า (`from`/`to`); เส้นของช่องที่ยังเหลือตัดจากเส้นนั้น (`sliceAlong`) ไม่คิดใหม่ ไถทิ้งที่ปลายหรือกลางเส้นจึงไม่ทำให้ส่วนที่เหลือขยับ และ undo ได้เส้นเดิม; ถนนแต่ละเส้นได้รูปตามที่วาด (เจ้าของโปรเจกต์ 18 ต.ค. 2026: "วาดแบบไหน จะได้แบบนั้น"): โหมดตรงเป็นเส้นตรงจาก A ถึง B, โหมดโค้งเป็นเส้นโค้งผ่านจุดที่คลิก (`shape`, `controls` ในคำสั่ง, `drawnLine`) เหมือนเส้นตัวอย่าง, ตารางวางทีละแถวและคอลัมน์เป็นถนนตรงของตัวเอง (`gridLines`, `part` ในคำสั่ง, undo ทั้งตารางทีเดียว) มุมเป็นมุม, วาดอิสระตามเมาส์แล้วเกลี่ย; เส้นที่วาดแล้วไม่โค้งเข้าหาเส้นเก่าเอง วาดตามแนวถนนเดิม (จัดแนว) จึงต่อเนียน วาดเป็นมุมก็ได้มุม

## 6. ระบบสาธารณูปโภค บริการส่วนกลาง และเศรษฐกิจจังหวัด

### 6.1 ไฟฟ้าและพลังงาน 6 ชนิด (`src/powerManager.js`, `src/powerPlants.ts`)
* **ไฟฟ้าวิ่งตามถนน:** โรงไฟฟ้าที่ตั้งติดถนนจะจ่ายกระแสไฟฟ้าไปตามโครงข่ายถนนโดยอัตโนมัติ (ไม่ต้องลากสายไฟในเมือง)
* **โรงไฟฟ้า 6 ชนิด:** ลิกไนต์ (`lignite`), ก๊าซธรรมชาติ (`gas`), เขื่อนผลิตไฟฟ้า (`hydro` ต้องตั้งติดน้ำและจังหวัดมีทรัพยากรน้ำ), โซลาร์ฟาร์ม (`solar`), กังหันลม (`wind`), และนิวเคลียร์ (`nuclear`)

### 6.2 ระบบประปาและน้ำบาดาล (`src/waterManager.ts`, `src/groundwater.ts`)
* ท่อประปาวิ่งใต้ถนนจาก **โรงประปา (`waterworks`)** ที่ได้รับไฟฟ้า
* ปริมาณน้ำที่สูบได้ขึ้นกับ **ระดับน้ำบาดาล (`groundwater`)** ใต้โรงประปา ซึ่งเติมกลับในฤดูฝนและลดลงในฤดูแล้ง (**หอประปา `watertower`** ช่วยสำรองน้ำในฤดูแล้ง)
* หากไม่มีน้ำประปา บ้านจะหยุดโตที่ระดับ 1 และอาคารขนาดใหญ่จะถดถอย

### 6.3 ขยะและน้ำเสีย 5 ชนิด (`src/waste.ts`)
* เมืองผลิตขยะและน้ำเสียตามจำนวนประชากรและโรงงาน หากไร้การจัดการ ขยะจะล้นถนน (`OVERFLOW_RISE`) ทำให้ราคาที่ดินและความพอใจดิ่งลง
* อาคารจัดการ 5 ชนิด: จุดพักขยะ (`transfer`), บ่อฝังกลบ (`landfill` มีความจุเต็มได้), โรงคัดแยกและรีไซเคิล (`recycle`), เตาเผาขยะผลิตไฟฟ้า (`incinerator`), และโรงบำบัดน้ำเสีย (`wastewater`)

### 6.4 การศึกษา สาธารณสุข และความปลอดภัย (`src/services.ts`)
* **การศึกษา:** โรงเรียนประถม (`primary`), มัธยม (`secondary`), วิทยาลัยอาชีวะ (`vocational`), มหาวิทยาลัย (`university`) — เพิ่มทักษะแรงงานและปลดล็อกอาคารพาณิชย์/อุตสาหกรรมขั้นสูง
* **สาธารณสุข:** รพ.สต./อนามัย (`clinic`), โรงพยาบาลชุมชน (`community`), โรงพยาบาลศูนย์ (`general`)
* **ความปลอดภัย:** สถานีตำรวจ (`police`) และสถานีดับเพลิง (`fire`)
* อาคารบริการส่วนกลางสามารถ **อัปเกรดระดับ (1–3)** เพื่อขยายรัศมีและความจุได้ (`src/buildingLevels.ts`)

### 6.5 ขนส่งมวลชน (`src/transit.ts`, `src/render3d/city/buses.ts`)
* ป้ายรถเมล์/สองแถว (`bus_stop` วางบนถนน), สถานีขนส่ง บขส. (`bus_terminal`), สถานีรถไฟ (`rail_station`), และสถานีรถไฟความเร็วสูง (`hsr_station`)
* ช่วยลดความหนาแน่นจราจรและเพิ่มการเติบโตของย่านพาณิชย์รอบสถานี

### 6.6 ทรัพยากรจังหวัด 17 ชนิด เกษตรกรรม เหมืองแร่ และการท่องเที่ยว (`src/geo/provinceResources.ts`)
* แต่ละจังหวัดมีระดับทรัพยากร 0–5 ใน 17 ด้าน (`data/province-profiles.json`):
  * **เกษตรและประมง (`src/farming.ts`):** ไร่นา (`farm`) และท่าประมง (`harbour`) สร้างรายได้แต่ใช้น้ำบาดาลและอาจเกิดฝุ่นควันตามฤดู
  * **เหมืองแร่และปิโตรเลียม (`src/mining.ts`):** หินปูน, โพแทช, ดีบุก, สังกะสี, ทองคำ, อัญมณี, แร่หายาก, น้ำมันและก๊าซ — จ่ายค่าภาคหลวงเข้าคลังแต่สร้างฝุ่นและมลพิษสะสมในดิน (`mining.ground`)
  * **การท่องเที่ยว (`src/tourism.ts`):** ดึงดูดนักท่องเที่ยวตามฤดูกาล ความสวยงามของเมือง และจำนวนร้านค้า สร้างรายได้ภาษีแต่เพิ่มขยะและจราจร

### 6.7 ที่ว่าการอำเภอ / ศาลากลางจังหวัด (`src/rulerHouse.ts`), ยศเจ้าเมือง (`src/rulerRank.ts`), ภาษี และนโยบาย
* **ต้องสร้างถนนก่อน แล้ววางที่ว่าการอำเภอติดถนน** จึงจะเริ่มวางเขตและบริการอื่นได้
* **ยศเจ้าเมือง 6 ขั้น:** หมื่น → ขุน → หลวง → พระ → พระยา → เจ้าพระยา (ปลดล็อกสิทธิ์ซื้อที่ดิน, งบประมาณ, ส่วนต่อเติมศาลากลาง 8 ปีก และอาคารขั้นสูง)
* **ภาษีแยก 3 ประเภท (`src/budget.js`):** ภาษีที่อยู่อาศัย, พาณิชย์, อุตสาหกรรม
* **นโยบายเมือง 7 ข้อ (`src/policies.ts`):** คัดแยกขยะ, รถเมล์ฟรี, ส่งเสริมท่องเที่ยว, มาตรฐานควันโรงงาน, ประหยัดน้ำ, กวดขันจราจร, ฝึกอาชีพ

## 7. ระบบตรวจสอบวัตถุและความพอใจ (`CityObject` & `Satisfaction`)

ทุกสิ่งที่คลิกได้ในเมือง (`src/inspect.ts`, `src/inspectCard.ts`) เป็นคลาสใน `src/objects/`:
* **`CommunityBuilding`:** บ้าน, ร้านค้า, โรงงาน, ไร่นา, ท่าประมง — คำนวณความพอใจ (0–100%) จากไฟฟ้า, น้ำประปา, ถนน, ขยะ, มลพิษ, อาชญากรรม, ภาษี, ราคาที่ดิน และบริการใกล้เคียง
* **`CentralService`:** โรงไฟฟ้า, ประปา, ขยะ, โรงเรียน, โรงพยาบาล, ตำรวจ, ดับเพลิง, สถานีขนส่ง, เหมือง, ที่ว่าการอำเภอ — แสดงประสิทธิภาพการทำงาน งบประมาณ และภาระงาน
* **แปลงที่ยังไม่งอกหรือหยุดโต (`whyPlotStalled` ใน `src/plots.ts`):** แจ้งสาเหตุชัดเจนเป็นภาษาไทยและแสดงไอคอนเตือนเหนือแปลงในมุมมอง 3D (`src/render3d/city/problemIcons.ts`)
