# คลังโมเดล 3D (Art archive)

เจ้าของโปรเจกต์ขอ (13 ต.ค. 2026): "ตอนนี้ฉันติดตั้ง blender แล้ว … ให้สร้างไฟล์ 3d เก็บไว้ เผื่อในอนาคต อาจมีการเปลี่ยนแปลง"

## ทำไมต้องมี

- **โมเดลของเกมเป็นโค้ด:** โมเดลทุกตัวเป็นโค้ด TypeScript ที่สร้างรูปทรงตอนเปิดเกม (`src/render3d/models/`) ไม่มีไฟล์ .blend หรือ .glb
- **git เก็บโค้ดทุกเวอร์ชันอยู่แล้ว** แต่เปิดดูหรือแก้ใน Blender ไม่ได้
- **คลังนี้:** เก็บภาพถ่าย (snapshot) ของโมเดลทุกตัวเป็นไฟล์ 3D ทุกครั้งที่ส่งออก
  - แต่ละรอบเก็บแยกโฟลเดอร์ รอบเก่าจึงไม่หาย
  - เปิดดูหรือแก้ได้ทั้งใน Blender และโปรแกรมอื่นที่อ่าน glTF

## ใช้อย่างไร

1. **ส่งออก:** `npm run art:export`
   - คำสั่งนี้เปิด dev server และหน้า `art-export.html`
   - หรือเปิด `/art-export.html` เองตอนที่ `npm run dev` ทำงานอยู่
   - กด "เริ่มส่งออก" ใช้เวลาราว 15 นาที ได้ 420 ไฟล์จาก 151 โมเดล
   - ช่อง "ทุกภาค" ส่งออกโมเดลระดับ R1 และ R2 ครบทั้ง 6 ภาค
2. **สร้างไฟล์ Blender:** `npm run art:blend`
   - สร้าง `phaicity-models.blend` ในรอบล่าสุด หรือระบุรอบเองด้วย `npm run art:blend -- <โฟลเดอร์รอบ>`
   - Blender รันเบื้องหลังโดยไม่เปิดหน้าต่าง ใช้เวลาราว 15 นาที
   - คำสั่งหา Blender จาก `BLENDER` ก่อน แล้วจาก PATH แล้วจาก `Program Files\Blender Foundation` ในไดรฟ์ C: D: E:

## เก็บที่ไหน

- **ที่เก็บ:** `D:\DesktopServer\www\phaicity-art\exports\<วันที่>_<เวลา>_<commit>\`
  - โฟลเดอร์ `phaicity-art` อยู่ข้างโฟลเดอร์โปรเจกต์ นอก git
  - เปลี่ยนที่เก็บได้ด้วยตัวแปร `PHAICITY_ART_DIR`
- **ขนาด:** รอบแรก (13 ต.ค. 2026, commit 35183f6) ใช้ 281 MB
  - ไฟล์ glTF รวม texture 197 MB
  - ไฟล์ .blend 88 MB
  - ไดรฟ์ D: ว่าง 437 GB เก็บได้หลายร้อยรอบ
- **ผลรอบแรก:** 420 โมเดล ส่งออกไม่สำเร็จ 0 ตัว
  - วัตถุใน Blender 3,760 ชิ้น
  - ภาพ 169 ภาพ ฝังในไฟล์ครบ
  - วัสดุ 377 แบบ

**ในแต่ละรอบมี:**

| ไฟล์ | คืออะไร |
|---|---|
| `models/<หมวด>/<ชื่อ>.gltf` และ `.bin` | โมเดลหนึ่งตัว: วัสดุและโครงสร้างอยู่ใน .gltf รูปทรงอยู่ใน .bin |
| `assets/textures/…` | texture ที่โมเดลใช้ร่วมกัน (CC0) เก็บชุดเดียว |
| `assets/CREDITS.md` | แหล่งที่มาของ texture |
| `generated/…` | ภาพที่เกมวาดเอง เช่น ป้ายไทยและลายปูน รวมถึง normal map ที่กลับช่องสีเขียวให้ตรงมาตรฐาน glTF ตั้งชื่อตามเนื้อหา จึงเก็บแค่ครั้งเดียว |
| `manifest.json` | รายการโมเดล: id ภาค variant state ระดับ (R1–R3) ขนาดเป็นช่อง จำนวนสามเหลี่ยม |
| `README.md` | commit และสัญญาอนุญาต |
| `phaicity-models.blend` และ `blender_assets.cats.txt` | คลัง Blender ที่ `art:blend` สร้าง |

**ชื่อโมเดล:** `<id>@<ภาค>-v<variant>-<state>` เช่น `res.house_0@north` หรือ `svc.stadium-game`

## ในไฟล์ Blender

- **โครงสร้าง:** คอลเลกชัน `PhaiCity` แบ่งตามหมวด แต่ละโมเดลเป็นคอลเลกชันของตัวเอง
  - วางเรียงแถว หนึ่งแถวต่อหนึ่งหมวด ช่องละ 10 เมตรตามเกม
- **Asset Browser:** ทุกโมเดลเป็น asset ในหมวด `PhaiCity/<หมวด>`
  - มีป้ายกำกับภาคและระดับ
  - คำอธิบายบอก id และจำนวนสามเหลี่ยม
- **texture:** ฝัง (pack) ในไฟล์ ไฟล์ .blend จึงเปิดได้เองโดยไม่ต้องมีโฟลเดอร์อื่น
- **วัสดุ:** วัสดุที่มาจากวัสดุเดียวกันของเกมรวมเป็นอันเดียว แก้ครั้งเดียวแล้วทุกโมเดลที่ใช้เปลี่ยนตาม

## สิ่งที่ไม่ได้มาด้วย

- **เอฟเฟกต์ที่เกมทำใน shader:**
  - ลายเม็ดปูนบนผนังทาสี
  - หน้าต่างเปิดไฟตอนกลางคืน
  - การวาง texture ตามพิกัดโลกในตัววาดเมือง
  - ไฟฉายและป้าย LED ที่ขยับ
  - ไฟล์จะได้แค่สีและ texture พื้นฐาน
- **การเคลื่อนไหว:** เช่น ใบพัดหรือรถ ไฟล์ได้แค่ท่านิ่งของ state นั้น
- **ต้นไม้และพุ่มไม้:** ใช้ seed 1 ในเกมแต่ละต้นจึงต่างจากในไฟล์ได้เล็กน้อย

## นำกลับเข้าเกม

- **ตอนนี้ส่งออกได้ทางเดียว** เพราะโมเดลในเกมเป็นโค้ด
- **แผน (รอเจ้าของตัดสินใจเรื่องรับงานกราฟิกต่อจาก Codex หลัง R5):**
  - **ชิ้นที่ต่อกันเป็นตาราง** (ถนน ราง พื้น เขตบ้านตามภาค): ยังเป็นโค้ดต่อไป ถ้าแก้ใน Blender เป็นแบบ ผมจะแปลงกลับเป็นโค้ด
  - **อาคารเด่นและ landmark:** ทำใน Blender แล้วเกมโหลด .glb จาก `assets/models/` ผ่าน registry ใช้ชื่อวัสดุของเกม เพื่อให้ได้ texture เอฟเฟกต์กลางคืนและวัสดุแบบเดียวกับโมเดลอื่น

## โค้ด

- **`art-export.html` และ `src/admin/artExport.ts`:** หน้าส่งออก ใช้เฉพาะ dev server ไม่อยู่ใน build
  - อ่านโมเดลจาก registry อย่างเดียว ไม่แก้ไฟล์ของ Codex
- **`scripts/art/artServer.mjs`:** endpoint ของ dev server
  - รับเฉพาะหน้าในเครื่องนี้ และเขียนได้แค่ในโฟลเดอร์ของรอบนั้น
  - คัดลอกได้แค่ไฟล์ใต้ `assets/textures` กับ `assets/CREDITS.md`
- **`scripts/blender/build_library.py` และ `scripts/blender/run.mjs`:** สร้างคลัง Blender
- **เทสต์:** `test/artExport.ts` (Jest) และ `test/geo/art.test.mjs` (`npm run test:geo`)
