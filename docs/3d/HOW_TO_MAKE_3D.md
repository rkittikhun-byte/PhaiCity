# วิธีสร้างภาพ 3D ของ PhaiCity ให้เป็นสไตล์เดียวกัน (สำหรับ AI หรือคนที่มาทำต่อ)

เจ้าของขอ (14 ต.ค. 2026): "เขียนวิธีการสร้างภาพ 3d ไว้ให้หน่อย เผื่อฉันเปลี่ยนไปใช้ ai เจ้าอื่น ให้มันอ่านๆ แล้วทำภาพออกมาจะได้
เป็น style เดียวกัน"

อ่านไฟล์นี้ก่อน แล้วอ่านเอกสารฉบับเต็มตามลำดับ:
1. `CLAUDE.md` (กติกาโปรเจกต์ ลิขสิทธิ์ สิ่งต้องห้าม)
2. `docs/3d/MODEL_SPEC.md` (สเปกโมเดล: หน่วย พิกัด ขนาด งบสามเหลี่ยม วัสดุ ภาค สัญญาของ factory)
3. `docs/3d/DETAIL_CHECKLIST.md` (รายละเอียดที่โมเดลแต่ละชนิดต้องมี)
4. `docs/3d/RENDERER_SPEC.md` (ตัววาดเมือง: อ่านอะไรจากแผนที่)
5. `docs/3d/MODEL_CATALOG.md` (มีโมเดลอะไรแล้ว ขาดอะไร) และ `docs/3d/CODEX_PROMPTS.md` (ใบสั่งงานแต่ละโมเดลที่ใช้มา)

## 1. หน้าตาที่ต้องการ

- **เมืองไทยร่วมสมัย แบบเกมสร้างเมือง Cities: Skylines** ไม่ใช่ระดับภาพยนตร์ กล้องมองจากสูงเอียง 45–60° และซูมลงถึงระดับถนนได้
- **เน้นตามลำดับ:** เงาโครงร่าง (silhouette) หลังคา สัดส่วนจริง วัสดุ แล้วค่อยรายละเอียดเล็ก
- **รายละเอียดไทย:** แอร์ เหล็กดัด ประตูเหล็กม้วน แท็งก์น้ำบนหลังคา จานดาวเทียม ราวตากผ้า ป้ายภาษาไทย (ชื่อสมมติ) กันสาด
  กระถางต้นไม้ ศาลพระภูมิ โอ่งมังกร
- **แต่ละภาคไม่เหมือนกัน (6 ภาค):** ชิ้นส่วนประจำภาคมาจาก kit ใน `src/render3d/regional/` เท่านั้น (MODEL_SPEC 6A)
  - R1 รูปทรงประจำภาค / R2 การแต่งประจำภาค / R3 แบบเดียวทั้งประเทศ
- **ใกล้ละเอียด ไกลเรียบ** และต้องลื่นบนโน้ตบุ๊กการ์ดจอในตัว
- **สีและแสง:** พื้นดินลูกรังส้มแดง (`dirt_laterite`) หญ้าเขียวอ่อน ท้องฟ้ามีเมฆ หมอกบางตามระยะ ไม่ใช้สีสดจัด
- **ห้าม:** ตราครุฑ สัญลักษณ์ราชวงศ์ กาชาด แบรนด์จริง พระพุทธรูป ช่อฟ้า ใบระกา หางหงส์บนอาคารที่ไม่ใช่วัด
  วัดทำได้ (โบสถ์ วิหาร เจดีย์ ศาลา หอระฆัง) แต่ต้องได้แรงบันดาลใจ ห้ามลอกของจริง (CLAUDE.md ข้อ 8)

## 2. วิธีทำโมเดล

- **โมเดลเป็นโค้ด** three.js + TypeScript ใน `src/render3d/models/<หมวด>/` แต่ละตัวเป็นฟังก์ชัน factory คืน `THREE.Group`
  ลงทะเบียนใน `src/render3d/models/registry.ts` ด้วย id เช่น `civic.ruler_house`, `rail.corner` (ไม่มีไฟล์ .glb ในเกม;
  ถ้ามีไฟล์จากศิลปินภายหลังให้สลับใน registry ด้วย id เดิม)
- **หน่วยในโมเดล:** 1 หน่วย = 1 เมตร ช่องละ 10 หน่วย ด้านหน้าหัน +Z จุดกำเนิดอยู่กลางฐานที่ y = 0 (MODEL_SPEC 2)
  - แผนที่อำเภอใช้ช่องละ 16 ม. จริง แต่ในฉาก 3D ยังเป็น 10 หน่วยต่อช่อง ภาพจึงขยาย 1.6 เท่า อาคารของเจ้าเมืองที่ติดถนน
    วาดที่ 0.6 ของช่อง (`BUILDING_SCALE` ใน `src/render3d/city/tileModels.ts`) จึงออกมาเกือบเท่าขนาดจริง
- **วัสดุ:** ใช้จาก `src/render3d/materials/library.ts` เท่านั้น ห้าม `new Material` ในไฟล์โมเดล เปลี่ยนสีด้วยฟังก์ชัน tint
  UV ตามสเกลโลก (`applyWorldUV`) texture CC0 ขนาด 1K จาก ambientCG/Poly Haven ลงบันทึกใน `assets/CREDITS.md`
- **ป้ายไทย:** CanvasTexture ฟอนต์ Sarabun/Noto Sans Thai ใน `assets/fonts/` ข้อความสมมติ ป้ายในโลก 3D เป็นภาษาไทยเสมอ
- **งบสามเหลี่ยมและ LOD:** ตาม MODEL_SPEC 4 ทุกโมเดลมีรุ่นไกล (กล่องสีหรือรุ่นเรียบ) ที่ตัววาดใช้เมื่ออยู่ไกล
- **ไฟล์ใหม่ใส่ header ของ PhaiCity** (GPL v3) ตาม MODEL_SPEC 8

## 3. ถนน ทางรถไฟ และการวางอาคาร (ตัววาดเมือง `src/render3d/city/`)

- **ถนนและทางรถไฟเป็นเส้นโค้งต่อเนื่อง** ไม่ใช่ทีละช่อง: `roadCurves.ts` วาดแต่ละช่วงระหว่างทางแยกตามเส้นเรียบจาก
  `src/roadGeometry.ts` (เฉลี่ยขั้นบันไดออก แล้วตัดมุมให้มน) ลูกรังเป็นแถบสีไล่ (`lateriteColour`) ลาดยางเทาเข้มมีไหล่ทางและเส้นกลาง
- **อาคารของเจ้าเมือง 3×3 ขึ้นไป** หันหน้าเข้าถนนที่ใกล้ที่สุดและชิดขอบถนนตามแนวโค้ง (`poseAgainstRoad`)
- **ช่องเขตแบบ CS:** ช่อง 2 ม. ตามแนวถนน (`src/zoneCells.ts`, `zoneCellsView.ts`) สีเขียว บ้าน / น้ำเงิน ร้านค้า / เหลือง โรงงาน
- **ภาพตัวอย่างตอนวาด:** แถบโปร่งตามเส้นที่จะสร้างจริงทุกโหมด สีตามชนิด มีเส้นประขาว (`overlay.ts`)
- **ตัววาดอ่านสถานะเมืองเท่านั้น ห้ามเขียนกลับ** (CLAUDE.md "Online plan" ข้อ 2)

## 4. ตรวจงาน

- `npm run gallery` เปิดแกลเลอรีโมเดลดูทุกตัวทุกภาค
- `npm test -- --runInBand test/render3d --coverage=false` (สัญญาโมเดล งบ วัสดุ ป้ายไทย)
- `npm run dev` แล้วเปิดเกม ดูในเมืองจริง ทั้งมุมไกลและซูมใกล้
- งานส่งออกเป็นไฟล์ให้ Blender: `npm run art:export` แล้ว `npm run art:blend` (`docs/3d/ART_ARCHIVE.md`)

## 5. คำสั่งตั้งต้นให้ AI ตัวอื่น (คัดลอกไปใช้ได้)

> คุณกำลังทำโมเดล 3D ให้เกม PhaiCity (เกมสร้างเมืองไทย three.js + TypeScript) อ่าน `docs/3d/HOW_TO_MAKE_3D.md`,
> `docs/3d/MODEL_SPEC.md` และ `docs/3d/DETAIL_CHECKLIST.md` ก่อนเริ่ม ทำโมเดลเป็นฟังก์ชัน factory ใน `src/render3d/models/`
> ใช้วัสดุจาก `materials/library.ts` เท่านั้น หน่วยเมตร ช่องละ 10 หน่วย ด้านหน้า +Z รองรับ `opts.region` ทั้ง 6 ภาค
> หน้าตาแบบ Cities: Skylines ในบรรยากาศเมืองไทยร่วมสมัย ห้ามของต้องห้ามตาม CLAUDE.md ข้อ 8 ลงทะเบียนใน `registry.ts`
> แล้วรัน `npm test -- --runInBand test/render3d --coverage=false` และดูใน `npm run gallery` ก่อนส่งงาน
