# โปรไฟล์จังหวัด และหน้าหลังบ้าน

เจ้าของโปรเจกต์ขอ (13 ต.ค. 2026): แต่ละจังหวัดมีทรัพยากรต่างกัน เช่น การท่องเที่ยว น้ำ ไฟฟ้า น้ำมัน แร่ต่าง ๆ รวมทั้งแร่หายาก
ระดับของแต่ละจังหวัดใช้วิธีอนุมาน ให้ผู้เล่นดูประกอบก่อนเลือกจังหวัด และ **ทุกอย่างมีได้ก็ต้องมีเสีย** เช่น สารพิษ หรือทรัพยากรหมด
แร่หายากไม่มีข้อมูลจริง ในเกมจึงสมมติขึ้น (เจ้าของ: "ในเกมส์ ก็ทำให้มีได้") และต้องมีหน้าหลังบ้านไว้ดูและกำหนดค่าเอง

ไฟล์นี้เป็นทั้งแผนและบันทึกงาน รายละเอียดที่ถูกต้องที่สุดอยู่ในโค้ด

## สิ่งที่แต่ละจังหวัดมี (ดูได้ก่อนเลือกเล่น)

| หมวด | สถานะ | มาจาก |
|---|---|---|
| 1. ภูมิประเทศ: ที่ราบ ป่า แหล่งน้ำ ภูเขา ความสูง | มีแล้ว | แผนที่จังหวัด (`data/maps`) |
| 2. การคมนาคม: ถนนลูกรัง ทางรถไฟ แม่น้ำ ทะเล สนามบิน | มีแล้ว | แผนที่จังหวัด |
| 3. ทรัพยากร: 17 อย่าง ระดับ 0–5 | **มีแล้ว (แสดงเป็นข้อมูล)** | ตารางด้านล่าง |
| 4. ภูมิอากาศและภัย: หน้าแล้ง น้ำท่วม พายุ ไฟป่า | มีแล้วบางส่วน | กติกาภาคและจังหวัด (`data/province-rules.json`) |
| 5. ผู้คนและอาชีพหลัก | ยังไม่มี | ต้องหาแหล่งข้อมูลประชากรที่ใช้ได้ตามไลเซนส์ก่อน |
| 6. ที่ตั้งและเพื่อนบ้าน: ด่านชายแดน ชายฝั่ง | มีแล้วบางส่วน | ด่านชายแดนจาก OpenStreetMap |
| 7. พื้นที่คุ้มครอง: อุทยานและป่าสงวน | มีแล้ว (แสดงเป็นข้อมูล) | OpenStreetMap |

## ทรัพยากร: ได้อะไร เสียอะไร

| ทรัพยากร | ได้ | เสีย | ระดับมาจาก |
|---|---|---|---|
| การท่องเที่ยว | ร้านค้าโต นักท่องเที่ยวมาใช้จ่าย | รถติด ขยะ ที่ดินแพง นักท่องเที่ยวหนีเมืองสกปรกหรือไม่ปลอดภัย มาเป็นฤดู | วัด: ที่พักและที่เที่ยว และชายหาด |
| แหล่งน้ำ | น้ำให้ประปาและเกษตร | หน้าฝนน้ำท่วม สูบหนักน้ำใต้ดินหมดหรือดินทรุด | วัด: สัดส่วนน้ำในแผนที่จังหวัด |
| ป่าไม้ | อากาศดี นักท่องเที่ยว เก็บน้ำไว้ใต้ดิน | ถางแล้วเสี่ยงน้ำท่วมและดินถล่ม | วัด: สัดส่วนป่าในแผนที่จังหวัด |
| ที่ดินเกษตร | อุตสาหกรรมเกษตรและอาหาร | เผาไร่เกิดหมอกควัน ใช้น้ำมาก สารเคมีลงน้ำ | วัด: ที่โล่งลบพื้นที่เมือง |
| ประมง | อาหารและรายได้ชายฝั่ง | จับมากเกินปลาหมด น้ำเสียทำให้ปลาลด | วัด: ความยาวชายฝั่งและบ่อเลี้ยง |
| พลังงานแสงอาทิตย์ | ไฟสะอาดไม่มีวันหมด | ใช้ที่ดินมาก กลางคืนไม่มีไฟ | วัด: โรงไฟฟ้าแสงอาทิตย์ |
| พลังน้ำ (เขื่อน) | ไฟถูกและสะอาด | อ่างเก็บน้ำท่วมป่า หน้าแล้งไฟลด | วัด: โรงไฟฟ้าพลังน้ำ อ่างเก็บน้ำ และความสูงต่ำของพื้นที่ |
| พลังงานลม | ไฟสะอาด | เสียงดัง ได้ไฟเฉพาะตอนลมพัด | อนุมาน |
| ถ่านหินลิกไนต์ | ไฟมากและถูก | ควันพิษ ฝนกรด คนป่วย ถ่านหมด | อนุมาน |
| น้ำมันและก๊าซธรรมชาติ | ค่าภาคหลวงทุกเดือน ดึงโรงงานปิโตรเคมี | น้ำมันรั่ว สารพิษ หลุมหมดรายได้หาย | อนุมาน |
| หินปูน | ปูนซีเมนต์และหินก่อสร้าง | ฝุ่น ภูเขาเป็นแผล | วัด: บ่อหินและเหมือง |
| โพแทชและเกลือหิน | ปุ๋ยและอุตสาหกรรมเคมี | ดินเค็มน้ำเค็มลาม พื้นดินยุบ | อนุมาน |
| ดีบุก | รายได้จากเหมือง | ตะกอนลงแม่น้ำและทะเล ต้องฟื้นฟูเหมือง | อนุมาน |
| สังกะสีและตะกั่ว | อุตสาหกรรมโลหะ | แคดเมียมและตะกั่วปนเปื้อนนา น้ำ และคน | อนุมาน |
| ทองคำ | มูลค่าสูง | ไซยาไนด์และสารหนูลงน้ำ ชาวบ้านต่อต้าน | อนุมาน |
| พลอย | การค้าพลอยและนักท่องเที่ยว | หลุมบ่อและโคลน | อนุมาน |
| แร่หายาก | มีค่ามาก ดึงอุตสาหกรรมไฮเทค | สกัดยาก มีกากสารเคมีและกากกัมมันตรังสีอ่อน | **สมมติในเกม** |

## ระดับมาจากไหน

ใช้ค่าแรกที่มี ตามลำดับนี้ (`src/geo/provinceResources.ts`)

1. **ตั้งเอง:** ค่าของเจ้าของ ใน `data/province-profiles.json` ช่อง `levels` แก้จากหน้าหลังบ้าน
2. **อนุมาน:** ค่าที่เกมเดาจากข้อมูลทั่วไปที่รู้กันในที่สาธารณะ ไม่ใช่ข้อมูลสำรวจ ช่อง `inferred` ในไฟล์เดียวกัน
   - เช่น ลิกไนต์ลำปาง น้ำมันบนบกกำแพงเพชร ก๊าซขึ้นฝั่งระยองและสงขลา โพแทชอุดรธานี สังกะสีตาก ดีบุกฝั่งอันดามัน พลอยจันทบุรี
   - การ์ดจังหวัดเขียนว่า "อนุมาน" และแร่หายากเขียนว่า "สมมติในเกม" เสมอ
3. **วัดได้:** นับจากฐานข้อมูลประเทศไทย (OpenStreetMap) และแผนที่จังหวัด ด้วย `npm run geo:indicators`
   แล้วเก็บไว้ใน `data/geo/province-indicators.json` จากนั้นเรียง 77 จังหวัดตามค่าที่วัดได้ จังหวัดที่ไม่มีเลยได้ 0
   ที่เหลือแบ่งเป็น 5 กลุ่มเท่า ๆ กัน ได้ระดับ 1–5

**ข้อจำกัดของข้อมูลที่วัดได้:** OpenStreetMap มีแค่สิ่งที่มีคนวาดไว้ จังหวัดที่วาดไว้ละเอียดจึงได้ค่าสูงกว่าความจริง
- เหมือง บ่อน้ำมัน และไร่นาใน OSM มีน้อยมาก จึงใช้การอนุมานหรือใช้ค่าอื่นแทน
- จำนวนอาคารใน OSM ไม่เท่ากันแต่ละจังหวัด ใช้แทนจำนวนคนไม่ได้
- ถ้าค่าไหนไม่ตรงความจริง ให้ตั้งเองในหน้าหลังบ้าน

## หน้าหลังบ้าน

เปิดได้เฉพาะเครื่องที่รัน `npm run dev` ที่ http://localhost:8080/admin.html (ไม่ได้อยู่ในเกมที่ build ออกไปให้ผู้เล่น)

- ทางซ้ายเป็นรายชื่อ 77 จังหวัด ค้นหาและกรองตามภาคได้ ★ คือจังหวัดที่ตั้งค่าเองไว้แล้ว
- คลิกจังหวัดแล้วเห็นข้อมูลที่วัดได้ทั้งหมด และตารางทรัพยากรแยกค่าวัดได้ อนุมาน ตั้งเอง และค่าที่ใช้จริง พร้อมสิ่งที่ได้และเสีย
- มีช่องหมายเหตุของเจ้าของ
- กติกาแก้ได้ทั้งของจังหวัดนั้นและของภาค:
  - ความต้องการเขต ไฟจากโรงไฟฟ้า ควันโรงงาน ค่าถางป่า หน้าแล้ง และราคาเครื่องมือทุกตัว
  - ช่องว่างคือใช้ค่าของชั้นถัดลงไป (ตัวเลขจาง)
  - ภัยตามฤดูยังแก้ในหน้านี้ไม่ได้ ต้องแก้ในไฟล์
- ส่วน "สิ่งที่ผู้เล่นเห็นบนการ์ดจังหวัด" อัปเดตทันทีที่แก้
- กด **บันทึก** แล้ว dev server ตรวจค่าด้วยกฎเดียวกับตัวเกม
  - ถ้ามีค่าผิด จะไม่บันทึกและบอกว่าผิดตรงไหน
  - ถ้าถูก จะเขียนลง `data/province-rules.json` และ `data/province-profiles.json` (คอมเมนต์ในไฟล์อยู่ครบ)
  - Git เก็บประวัติให้ ย้อนกลับได้เสมอ
- รับบันทึกเฉพาะจากหน้าที่เปิดบนเครื่องนี้ (`scripts/admin/adminServer.mjs`)
- **เมื่อขึ้นเซิร์ฟเวอร์:** หน้าเดิมจะย้ายไปอ่านเขียนตารางในฐานข้อมูลของเซิร์ฟเวอร์ และเปิดได้เฉพาะบัญชีเจ้าของ (ONLINE_PLAN 5.2)

## ขั้นต่อไป (เสนอ ยังไม่ทำ)

ทำทีละอย่างตามลำดับนี้ แต่ละอย่างต้องมีทั้งได้และเสีย:
1. **ท่องเที่ยว: ทำแล้ว (13 ต.ค. 2026)** ดู `docs/TOURISM.md` ทรัพยากรอื่นยังเป็นข้อมูลให้ดูอย่างเดียว
2. **ชนิดโรงไฟฟ้า:** เขื่อน แสงอาทิตย์ ลม ก๊าซ ลิกไนต์ สร้างได้หรือถูกลงตามระดับของจังหวัด แต่ละชนิดมีข้อเสียของตัวเอง
3. **เหมืองและบ่อน้ำมัน:** สร้างบนแหล่งแร่ ได้รายได้และความต้องการโรงงาน สารพิษลามลงดินและน้ำใต้ดิน และแร่หมด (ลดลงเหมือนน้ำใต้ดิน)
4. **เกษตร:** หมอกควันหน้าแล้ง การใช้น้ำ
5. **เล่นออนไลน์:** ไม่มีจังหวัดไหนมีครบทุกอย่าง จึงค้าขายกับเพื่อนบ้าน (ONLINE_PLAN 5.3)
