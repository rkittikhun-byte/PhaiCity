# ยานพาหนะของ PhaiCity ตามยุค (3D, Blender)

รถทุกคันที่วิ่งในเกมทำเป็นโมเดล 3D ใน Blender 5.2 ตามภาพ concept `assets/concept/era1_C_vehicles.jpg` …
`era5_C_vehicles.jpg` ขนาดจริงเป็นเมตร และเปลี่ยนตามยุคของเมืองเหมือนคนและบ้านเรือน (เจ้านาย 22 ต.ค. 2026:
"รถที่มาวิ่ง ... ให้วิ่งตามยุค ตามสมัยได้ไหม")

| ยุค | ที่วิ่งบนถนน |
|---|---|
| 1 หมู่บ้านเกษตร | เกวียนควาย เกวียนวัว จักรยาน รถเข็นของ |
| 2 เมืองตลาด | รถเมล์แดง สองแถว สามล้อถีบ รถเครื่องรุ่นแรก รถบรรทุกหัวยาว; ใต้มีรถโพถ้อง อีสานมีรถอีแต๋น |
| 3 เมืองโรงงาน | ตุ๊กตุ๊ก กระบะ กระบะคอกเหล็ก รถบรรทุกตู้หกล้อ วินมอเตอร์ไซค์ มอเตอร์ไซค์ รถเมล์ปรับอากาศ |
| 4 เมืองสมัยใหม่ | รถเก๋งเล็ก รถเก๋ง แท็กซี่ รถตู้ กระบะสี่ประตู มอเตอร์ไซค์ส่งอาหาร รถเมล์ชานต่ำ |
| 5 เมืองอนาคต | รถรับส่งไร้คนขับ รถไฟฟ้าแคปซูล รถยนต์ไฟฟ้า สกู๊ตเตอร์ไฟฟ้า แท็กซี่บินได้ โดรนขนของ |

- **ดูภาพรวม:** `previews/all_eras.png` และ `previews/era<ยุค>_vehicles.png` (เทียบกับภาพ concept ของยุคนั้น)
- **ดูในเบราว์เซอร์:** `npm run dev` แล้วเปิด `era-buildings.html` หัวข้อ "ยานพาหนะ" (เลือกยุคและภาค ล้อหมุนได้)
- **ในเกม:** รถของการเดินทางจริง (`src/render3d/city/tripCars.ts`) รถที่วิ่งเล่นบนถนน และรถเมล์ของขนส่งสาธารณะ
  เป็นแบบของยุคและภาคของเมือง ตามสัดส่วนในตาราง (`src/render3d/city/eraVehicles.ts`); ช่วงที่เมืองกำลังจะขึ้นยุค
  รถของยุคถัดไปค่อยๆ มาตามจำนวนบ้านที่เปลี่ยนแล้ว ภาคเหนือรถเมล์เป็นสองแถวแดง
- ป้ายทะเบียนเป็นแผ่นว่างลายสมมติ ไม่มียี่ห้อหรือโลโก้ (CLAUDE.md ข้อ 8)

## สร้างใหม่

ไฟล์ .blend สร้างจากสคริปต์ใน `scripts/` ทุกครั้ง จึงไม่ได้เก็บใน git:

```bash
./run.sh all
./run.sh export
```

`./run.sh era3 --only tuktuk --closeups` สร้างแค่บางแบบเป็นภาพใน `previews/era3/` ไว้ดูเร็วๆ
`export` เขียน `assets/models/vehicles/era<ยุค>/<แบบ>.glb` กับ `index.json` ที่เกมอ่าน
